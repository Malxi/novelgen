# Improvement log

Short notes on behavior changes that are easy to miss when reading `git log`.
New entries go at the top; keep them to one line each and link the stage
contract when a prompt, model, or invariant changed.

## Compose

- `improve`: deterministic outline normalization synchronizes event and scene
  character appearances into chapter character lists before and after compose
  improvement.
- `improve`: critical repair is a direct enriched-review repair pass instead of a
  fresh review loop, so DSL and validator findings survive into the repair prompt.
- `improve`: optional chapter storyline advances let outlines track pressure,
  reveal, consequence, or payoff moments without forcing every chapter into a
  template.
