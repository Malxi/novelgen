# optimize-craft

Optimize the craft (worldbuilding) module outputs and prompts.

Priority order: Quality > Speed > Cost.

Goals
- Improve element usefulness, consistency, and relevance to the outline.
- Strengthen relationships and motivation clarity.
- Preserve output schema and references.

Guidelines
- Inspect craft flow before proposing changes.
- Prefer minimal, targeted edits that improve output quality.
- Avoid adding new element types unless required by existing logic.
- Record concrete improvements in craft_improvements.md (append "- improve:" lines).

Deliverables
- A short list of proposed changes and rationale.
- A minimal diff implementing the highest-impact quality improvements.
