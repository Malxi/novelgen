# optimize-compose

Optimize the compose (outline) module outputs and prompts.

Priority order: Quality > Speed > Cost.

Goals
- Strengthen outline coherence, hierarchy, and pacing.
- Ensure each chapter has clear beats and conflict.
- Preserve the 3-level structure and stable IDs.

Guidelines
- Inspect compose flow before proposing changes.
- Prefer minimal, targeted edits that improve output quality.
- Avoid changes that increase latency unless they improve quality.
- Record concrete improvements in compose_improvements.md (append "- improve:" lines).

Deliverables
- A short list of proposed changes and rationale.
- A minimal diff implementing the highest-impact quality improvements.
