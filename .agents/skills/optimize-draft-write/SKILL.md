# optimize-draft-write

Optimize the draft and write module outputs and prompts.

Priority order: Quality > Speed > Cost.

Goals
- Improve prose quality, continuity, and constraint adherence.
- Enforce POV/tense consistency and avoid OOC behavior.
- Preserve output format and chapter structure.

Guidelines
- Inspect draft/write flow before proposing changes.
- Prefer minimal, targeted edits that improve output quality.
- Avoid changes that increase cost unless quality meaningfully improves.
- Record concrete improvements in draft_write_improvements.md (append "- improve:" lines).

Deliverables
- A short list of proposed changes and rationale.
- A minimal diff implementing the highest-impact quality improvements.
