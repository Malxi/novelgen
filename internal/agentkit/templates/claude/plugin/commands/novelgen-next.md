Read `.novelgen/workflows/setup.md`, `outline.md`, and `write.md` as needed.
Determine the next step from project state, then execute it through the
`novelgen` CLI. Use `novelgen tool replace ... --apply` for a complete setup/outline, and
`novelgen tool patch chapter --apply` for a chapter.

Never write `story/` or `chapters/` directly.
