# Craft Review Organizations Skill

## Purpose
Review generated organization/faction profiles for story usefulness, consistency, and downstream write/RPG readiness.

## Input
- `story_setup`: Story setup
- `outline`: Outline summary
- `organizations`: Organization profiles to review
- `iteration`: Current review iteration

## Output
- `result`: Review result with overall score and suggestions

## Review Criteria

Evaluate:
1. Each organization has a clear type, goals, resources, and story significance
2. Faction behavior aligns with setup rules, premises, resources, and relevant chapters
3. Allies/enemies and leadership do not contradict the outline
4. Goals create usable pressure for future prose, not vague background lore
5. Organizations do not duplicate ability systems owned by setup premises
6. RPG/DSL metadata is conservative, static, and useful when present
7. Output preserves all existing organization keys

## Suggestions

Use high priority for:
- Missing requested organizations
- Contradictions with setup or outline
- Organizations that redefine setup ability systems
- Vague goals/resources/significance that cannot guide writing

Keep all review text in the specified language.
