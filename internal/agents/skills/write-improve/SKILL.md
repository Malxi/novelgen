# Write Improve Skill

## Purpose
Improve final chapter content based on detailed review feedback.

## Input
- `story_setup`: The story setup for context
- `chapter`: Chapter information
- `state_matrix`: Current story state
- `target_words`: Target word count
- `current_draft`: The current chapter content
- `suggestions`: Review suggestions for improvement
- `context`: Continuity context
- `recap`: Canonical recap

## Output
- `content`: The improved final chapter content

## Guidelines

1. **Address all feedback** - Implement every suggestion appropriately
2. **Preserve strengths** - Don't lose what works well
3. **Elevate quality** - Make it better, not just different
4. **Maintain polish** - Keep publication-quality standards
5. **Ensure consistency** - Changes must fit with rest of story

## Improvement Focus Areas

### High Priority
- Plot logic errors
- Character inconsistencies
- Continuity breaks
- Missing or weak beats

### Medium Priority
- Pacing improvements
- Dialogue enhancement
- Description strengthening
- Emotional impact

### Low Priority
- Word choice refinement
- Sentence rhythm
- Minor style tweaks

## Output Requirements

Return only the improved chapter text. No explanations, no change lists, no meta-commentary.
