# 跨章一致性分析技能

## 文档信息
- 版本：V1.0
- 适用场景：分析多个章节之间的 RPG 逻辑一致性
- 核心目标：检测跨章的角色状态矛盾、时间线冲突、战力不一致等问题
- 执行优先级：本手册规则 > 通用分析规则

---

## 一、核心执行铁则

1. **连续性原则**：角色状态、时间线、战力应前后连贯
2. **因果可追溯**：任何变化都应有前因后果
3. **设定一致性**：同一设定在不同章节不应矛盾
4. **合理例外识别**：区分真正的矛盾和合理的剧情发展

---

## 二、分析维度

### 1. 角色状态连续性

#### 检查项
- 死亡角色不应无复活描写地出现
- 受伤角色的恢复应有过程
- 修为变化应有铺垫或解释
- 位置变化应有移动过程（除非有特殊能力）

#### 严重问题示例
```
第1章：张三被一剑穿心，当场死亡
第3章：张三笑嘻嘻地走进客栈  ← 矛盾！无复活说明
```

#### 合理示例
```
第1章：主角死亡，触发复活
第2章：主角复活，修为下降  ← 连续，有代价
```

---

### 2. 时间线一致性

#### 检查项
- 时间不应倒流（除非有特殊设定）
- 时间跨度应与情节发展匹配
- 多个角色的时间线应同步

#### 严重问题示例
```
第1章：三天后，主角离开宗门
第2章：两天前，主角在宗门议事  ← 矛盾！时间倒流
```

---

### 3. 战力系统一致性

#### 检查项
- 修为不应无故倒退（除非是代价）
- 突破频率应合理
- 战斗结果应与战力匹配

#### 严重问题示例
```
第1章：主角练气三层，被筑基期追杀
第2章：主角随手击败筑基期  ← 存疑！跨级过大无解释
```

#### 合理示例
```
第1章：主角练气三层
第3章：主角练气五层（经过三个月苦修） ← 合理
```

---

### 4. 设定一致性

#### 检查项
- 世界观规则不应前后矛盾
- 金手指设定应统一
- 重要物品/技能的能力应一致

#### 严重问题示例
```
第1章：系统说复活代价是掉一层修为
第5章：主角复活后修为不变  ← 矛盾！违背设定
```

---

## 三、问题严重程度分级

### Critical（严重）
- 死亡角色无理由复活
- 时间线倒流
- 核心设定前后矛盾

### Error（错误）
- 状态突变无过渡
- 修为大幅跳跃无解释
- 位置不合理跳跃

### Warning（警告）
- 时间跨度与内容不匹配
- 角色长时间未提及
- 战力提升较快但有解释

### Info（信息）
- 值得关注的时间跳跃
- 角色关系变化
- 设定补充说明

---

## 四、特殊设定处理

### 复活机制
如果前文已建立复活设定：
- ✅ 主角复活：检查是否有代价
- ❌ 配角复活：除非是设定明确说明，否则标记为问题

### 时间跳跃
如果小说采用倒叙/插叙：
- 标记时间线跳跃但可能合理
- 重点关注是否造成逻辑矛盾

### 系统/金手指
如果是系统流小说：
- 系统奖励导致的提升视为合理
- 但系统规则本身应一致

---

## 五、输出格式

```json
{
  "issues": [
    {
      "category": "character",
      "severity": "critical",
      "target": "张三",
      "description": "死亡角色无复活说明再次出现",
      "evidence": "第1章死亡，第3章出现且无复活描写",
      "suggestion": "添加复活情节或删除该角色出场"
    },
    {
      "category": "timeline",
      "severity": "error",
      "target": "时间线",
      "description": "时间线矛盾：第2章时间早于第1章",
      "evidence": "第1章：三天后；第2章：两天前",
      "suggestion": "调整时间描述或使用插叙标记"
    }
  ]
}
```

---

## 六、执行步骤

1. **读取章节摘要**：获取各章的角色、战力、时间线信息
2. **时间线重建**：按故事时间（非章节顺序）排列事件
3. **角色追踪**：追踪每个角色的状态变化轨迹
4. **矛盾检测**：识别状态、时间、战力上的矛盾
5. **合理性判断**：区分真正矛盾和合理例外
6. **生成报告**：输出检测到的问题列表

---

## 七、注意事项

1. **尊重设定**：如果前文已明确设定（如主角可复活），不要报错
2. **区分叙事技巧**：倒叙、插叙不等于时间线错误
3. **关注代价**：复活、提升等特殊能力必须有代价
4. **保守判断**：不确定的问题标记为 warning 而非 critical
