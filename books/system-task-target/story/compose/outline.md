# Story Outline

## 第一部：从新手耗材到外挂公敌

**Summary:** 白烬从青岚宗杂役开局，没有系统护身，却能看见宿主核心日志。开局最强对手不是随手找茬的大师兄，而是死亡回档归来的顾衡：一个月后的宗门大比里，顾衡败于白烬并身死，所以他提前回来调查、封路、试招。顾衡越想阻止未来，越把未来白烬的成长线索暴露给现在的白烬。白烬由此学会反读外挂，把宿主的任务、误判和未来记忆都变成自己的攻略。

### 第一卷：杂役白烬，未来败者来查我

**Summary:** 白烬穿越青岚宗杂役房，发现自己没有系统，却偶尔能看见宿主泄出的一条核心日志。开局最强对手是死亡回档归来的顾衡：白烬第一次只看见顾衡三十日后在宗门大比败于自己而死。与此同时，苏瑶只泄出一条机缘预告：陆青禾将在月夜旧演武台引动断剑共鸣，得到藏剑崖入崖令。第一卷的关键不是白烬全知，而是他用这两条极窄信息，帮陆青禾保住机缘，并从月下三鸣里拿到对抗顾衡的第一份优势：听剑意回响，找到顾衡护人时的右肩破绽。

**Payoff Contract:**
- **Volume Question:** 一个现在毫无修为的杂役，为什么会在一个月后的大比上打死大师兄？而月下断剑三鸣，会不会被苏瑶冒领走？
- **Power Promise:** 白烬不能读档，也没有奖励；他只能看见每个宿主当前阶段的一条核心日志，再靠观察和试错补全缺口。
- **Main Opponent Misread:** 顾衡以为白烬知道未来赢法，苏瑶以为白烬看穿了关键现场的见证顺序；实际上白烬只拿到死讯或机缘事实，真正的计划都靠现场反推。
- **Big Win:** 月夜旧演武台，白烬没有替陆青禾抢机缘，只把她带回守崖人问话现场，让她亲自续出第二、第三声剑鸣；随后他把“听回响”的剑意提示用到顾衡身上，第一次看见大师兄右肩线的破绽。
- **Visible Reward:** 获得半张吐纳残页、陆青禾信任、听剑意回响的提示、藏剑崖旧阶剑痕、顾衡护人时右肩线破绽，以及避锋半步雏形。
- **Reputation Shift:** 白烬从普通杂役，变成顾衡眼里越来越接近未来败局的人，也变成苏瑶眼里“总在关键时刻出现”的低位杂役。
- **Next Bigger Game:** 顾衡进入强制封路阶段，苏瑶开始追查白烬为什么能让机缘回到陆青禾手里，第二卷围绕“回档者越封路越喂招”展开。

#### 杂役房里的未来死讯

**Summary:** 白烬穿越到青岚宗杂役房，发现自己没有系统，却看见大师兄顾衡身边浮出唯一一条回档日志：死亡回档成功；死亡时间，三十日后的宗门大比；死亡原因，败于白烬。

**Characters:** 白烬, 顾衡, 杂役管事

**Location:** 青岚宗杂役房

**Events:**
- **白烬** → discover → 杂役房里的未来死讯 (knowledge) @ 青岚宗杂役房 | 白烬在杂役房通铺醒来，确认自己成了没有修为、没有系统面板的底层杂役。
- **顾衡** → progress → 未来大比败局 (goal) @ 青岚宗杂役房 | 顾衡面前浮出半透明日志：死亡回档成功；死亡时间，三十日后宗门大比；死亡原因，败于白烬。
- **白烬** → use → 核心日志 (skill) @ 青岚宗杂役房 | progressed

**Beats:**
1. 白烬在杂役房通铺醒来，确认自己成了没有修为、没有系统面板的底层杂役。
2. 杂役管事催他去晨洒，他第一次见到青岚宗大师兄顾衡，周围弟子对顾衡敬畏有加。
3. 顾衡面前浮出半透明日志：死亡回档成功；死亡时间，三十日后宗门大比；死亡原因，败于白烬。
4. 白烬意识到顾衡拥有死亡回档的能力，并且会在三十日之后的大比输给自己，担心自己被顾衡针对。
5. 顾衡温和地问了白烬两句话，白烬装作粗笨杂役，心里记下了顾衡的系统日志内容。

**Opening Beat:** 白烬在杂役房通铺醒来，确认自己成了没有修为、没有系统面板的底层杂役。

**Closing Beat:** 顾衡温和地问了白烬两句话，白烬装作粗笨杂役，心里记下了顾衡的系统日志内容。

**State Change:** 白烬确认自己的能力不是读完整面板，而是偶尔看见宿主泄出的一条核心日志；顾衡的第一条日志只有死亡回档、死亡时间、死亡原因。

**Chapter Payoff:**
- **Desire:** 白烬想活过本章，并多看懂一点顾衡的未来记忆。
- **Pressure:** 白烬刚穿越就被未来败给他的顾衡盯上；顾衡不敢直接杀，因为他要弄清这个杂役一个月后为何能赢。
- **Clever Move:** 白烬不假装知道未来，只把这条死讯当警报，先隐藏自己能看见日志。
- **Payoff Moment:** 日志停在“败于白烬”四个字，白烬反而更紧张：最关键的赢法没有出现。
- **Reward:** 白烬确认自己的能力不是读完整面板，而是偶尔看见宿主泄出的一条核心日志；顾衡的第一条日志只有死亡回档、死亡时间、死亡原因。
- **Social Proof:** 顾衡越查越觉得白烬不对劲，白烬却越查越知道未来的自己为什么能赢。
- **Hook:** 顾衡只问了两句话，却像在确认白烬到底凭什么会在三十日后赢他。

**Storyline Advances:**
- **青岚宗四宿主局** (pressure): 白烬确认自己的能力是看见宿主日志，也确认顾衡的冲突源来自未来大比败局。 | consequence: 顾衡的未来败局不断把白烬推到更多宿主视野里。 | pressure: 白烬刚穿越就被未来败给他的顾衡盯上；顾衡不敢直接杀，因为他要弄清这个杂役一个月后为何能赢。

**Conflict:** 白烬刚穿越就被未来败给他的顾衡盯上；他只知道一条死讯，不知道顾衡接下来要怎么查他。

**Pacing:** normal

#### 大师兄的第一次试剑

**Summary:** 顾衡借晨课演示之名挑白烬搬剑靶，试探他是否隐藏修为。白烬看不见试探条件，只从顾衡选择“剑靶入手”这个动作里猜到其中有检测，故意用杂役笨办法避开。

**Characters:** 白烬, 顾衡, 外门弟子, 杂役管事

**Location:** 青岚宗晨课场

**Events:**
- **白烬** → discover → 大师兄的第一次试剑 (knowledge) @ 青岚宗晨课场 | 晨课场上，顾衡被请来演示基础剑理，所有外门弟子都把他当成标准答案。
- **顾衡** → progress → 未来大比败局 (goal) @ 青岚宗晨课场 | 白烬发现剑靶把手处刻着细小阵纹，猜到顾衡想借入手瞬间查经脉反应。
- **白烬** → use → 核心日志 (skill) @ 青岚宗晨课场 | progressed

**Beats:**
1. 晨课场上，顾衡被请来演示剑理，所有外门弟子都把他当成标准答案。
2. 顾衡点名让白烬搬剑靶，理由温和合理，旁人只当大师兄照顾杂役。
3. 白烬没有看见新日志，只记得顾衡会死在宗门大比，便警惕他每一个看似随手的安排。
4. 他发现剑靶把手处刻着细小阵纹，猜到顾衡想借入手瞬间查经脉反应。
5. 他故意把剑靶扛偏，用肩背和麻绳受力，不让掌心直接贴住检测阵纹。
6. 顾衡没有查出修为，却注意到白烬避开的动作太巧；白烬也确认顾衡未来输的大概率是剑局。

**Opening Beat:** 晨课场上，顾衡被请来演示剑理，所有外门弟子都把他当成标准答案。

**Closing Beat:** 顾衡没有查出修为，却注意到白烬避开的动作太巧；白烬也确认顾衡未来输的大概率是剑局。

**State Change:** 顾衡的怀疑加深，白烬则从剑靶阵纹和顾衡的试探动作里确认：未来胜负大概率和剑道资源有关。

**Chapter Payoff:**
- **Desire:** 白烬想活过本章，并多看懂一点顾衡的未来记忆。
- **Pressure:** 顾衡以大师兄职责做掩护试探白烬，白烬必须像普通杂役一样出丑，同时不能真的暴露日志能力。
- **Clever Move:** 白烬不靠日志答案，而是检查顾衡递来的器物，用杂役搬运方式避开检测。
- **Payoff Moment:** 顾衡没有查出修为，却第一次觉得这个杂役的“笨”不太自然。
- **Reward:** 顾衡的怀疑加深，白烬则从剑靶阵纹和顾衡的试探动作里确认：未来胜负大概率和剑道资源有关。
- **Social Proof:** 顾衡越查越觉得白烬不对劲，白烬却越查越知道未来的自己为什么能赢。
- **Hook:** 顾衡对藏剑崖方向的封锁来得太早，白烬决定先弄清那是什么地方。

**Storyline Advances:**
- **青岚宗四宿主局** (pressure): 顾衡的怀疑加深，白烬则从剑靶阵纹和顾衡动作中判断“剑道资源”可能是未来胜负关键。 | consequence: 顾衡的未来败局不断把白烬推到更多宿主视野里。 | pressure: 顾衡以大师兄职责做掩护试探白烬，白烬必须像普通杂役一样出丑，同时不能真的暴露日志能力。

**Conflict:** 顾衡用晨课试探白烬底细；白烬没有新日志，只能从器物和动作判断危险。

**Pacing:** normal

#### 三条被封的路

**Summary:** 顾衡开始调整杂役活动范围，白烬看不见封路清单，只能从执事新贴的禁行牌、巡查弟子的位置和顾衡停留时间，推断藏剑崖、旧演武台、丹房废炉可能都和未来败局有关。

**Characters:** 白烬, 顾衡, 杂役管事

**Location:** 杂役房外山道

**Events:**
- **白烬** → discover → 三条被封的路 (knowledge) @ 杂役房外山道 | 白烬被派去清扫山道，远远看见顾衡与执事交谈，似乎在调整杂役行动范围。
- **顾衡** → progress → 未来大比败局 (goal) @ 杂役房外山道 | 白烬意识到顾衡越想堵路，越是在告诉他哪些地方重要。
- **白烬** → use → 核心日志 (skill) @ 杂役房外山道 | progressed

**Beats:**
1. 白烬被派去清扫山道，远远看见顾衡与执事交谈，似乎在调整杂役行动范围。
2. 这一次没有日志浮现，只有几块新挂的禁行牌和临时换岗的巡查弟子。
3. 白烬把顾衡停留最久的三个方向记下来：藏剑崖、旧演武台、丹房废炉。
4. 他借送扫帚的机会绕到旧演武台，发现石地上有被岁月磨平的剑步刻痕。
5. 顾衡的巡查提前到来，白烬装作迷路搬杂物，差点被看穿。
6. 他离开前记住一组残缺步点：三进一退，斜走半尺。

**Opening Beat:** 白烬被派去清扫山道，远远看见顾衡与执事交谈，似乎在调整杂役行动范围。

**Closing Beat:** 他离开前记住一组残缺步点：三进一退，斜走半尺。

**State Change:** 白烬第一次从顾衡的封锁中偷到未来成长线索，获得旧演武台残缺步点。

**Chapter Payoff:**
- **Desire:** 白烬想活过本章，并多看懂一点顾衡的未来记忆。
- **Pressure:** 白烬必须在顾衡封路之前偷看关键地点，又不能让顾衡确认他真的在追未来路线。
- **Clever Move:** 白烬把禁行牌、巡查换岗和顾衡停留时间当成线索，而不是等日志给答案。
- **Payoff Moment:** 顾衡的巡查提前到来，白烬装作迷路搬杂物，差点被看穿。
- **Reward:** 白烬第一次从顾衡的封锁中偷到未来成长线索，获得旧演武台残缺步点。
- **Social Proof:** 顾衡越查越觉得白烬不对劲，白烬却越查越知道未来的自己为什么能赢。
- **Hook:** 丹房废炉暂时没被封，反而成了白烬下一步最安全的入口。

**Storyline Advances:**
- **青岚宗四宿主局** (pressure): 白烬第一次从顾衡的封锁中偷到未来成长线索，获得旧演武台残缺步点。 | consequence: 顾衡的未来败局不断把白烬推到更多宿主视野里。 | pressure: 白烬必须在顾衡封路之前偷看关键地点，又不能让顾衡确认他真的在追未来路线。

**Conflict:** 顾衡开始封路，但白烬看不见封路清单；他必须从宗门调度和顾衡脚步里推断真正方向。

**Pacing:** normal

#### 苏瑶提前一天看见机缘

**Summary:** 苏瑶的机缘截胡系统提前一天泄出一条核心日志：原主陆青禾，明夜子时，旧演武台，断剑三鸣，结果为藏剑崖入崖令。日志没有截胡方法。白烬靠近旧演武台时撞见苏瑶打听陆青禾夜练时辰、守崖人巡夜路线和顾衡常走的山道，才推断她不是要抢剑法，而是要抢“谁被守崖人看见”的那一刻。

**Characters:** 白烬, 顾衡, 苏瑶, 陆青禾, 外门弟子

**Location:** 旧演武台外廊

**Events:**
- **白烬** → discover → 苏瑶提前一天看见机缘 (knowledge) @ 旧演武台外廊 | 白烬继续追查顾衡频繁关注的旧演武台，发现苏瑶也在打听陆青禾夜练时辰和守崖人巡夜路线。
- **苏瑶** → progress → 旧演武台断剑共鸣机缘 (storyline) @ 旧演武台外廊 | 苏瑶身边闪过一条极短日志：机缘原主，陆青禾；时间，明夜子时；地点，旧演武台；结果，藏剑崖入崖令。
- **白烬** → use → 核心日志 (skill) @ 旧演武台外廊 | 白烬确认苏瑶只泄出机缘归属事实；入崖令可能与顾衡未来败局有关，但真正有用的是守崖人这一层见证。

**Beats:**
1. 白烬继续查旧演武台线索，发现苏瑶也在打听陆青禾夜练时辰。
2. 苏瑶身边闪过一条极短日志：机缘原主，陆青禾；时间，明夜子时；地点，旧演武台；结果，藏剑崖入崖令。
3. 日志没有告诉白烬苏瑶要怎么抢，只说明这份机缘本该落到陆青禾手里。
4. 苏瑶又打听守崖人巡夜路线，还安排外门弟子明夜在山道口传话，谎称顾衡找陆青禾。
5. 白烬这才推断出她要抢的不是剑招，而是第一声剑鸣后的见证现场：谁站在台上，谁就可能被守崖人记住。
6. 他不能提醒陆青禾“明夜有机缘”，只能决定明夜守在山道附近，看苏瑶会不会真的用顾衡的名义支开她。

**Opening Beat:** 白烬继续查旧演武台线索，发现苏瑶也在打听陆青禾夜练时辰。

**Closing Beat:** 他不能提醒陆青禾“明夜有机缘”，只能决定明夜守在山道附近，看苏瑶会不会真的用顾衡的名义支开她。

**State Change:** 确认苏瑶的系统类型为机缘截胡，但白烬只能看见机缘原主、时间、地点和结果；截胡方式来自苏瑶自己的布置。

**Chapter Payoff:**
- **Desire:** 白烬想保住顾衡未来败因相关线索，同时不暴露自己能看见日志。
- **Pressure:** 白烬只知道机缘归属，不知道苏瑶的截胡步骤；他必须从她打听守崖人、安排传话的动作里反推关键条件。
- **Clever Move:** 白烬不正面揭穿苏瑶，只守住传话山道和守崖人路线，等她自己暴露截胡手法。
- **Payoff Moment:** 白烬看见“机缘原主：陆青禾”后，又看见苏瑶打听守崖人，这才明白真正要被抢走的是见证现场。
- **Reward:** 确认苏瑶的系统类型为机缘截胡，但白烬只能看见机缘原主、时间、地点和结果；截胡方式来自苏瑶自己的布置。
- **Social Proof:** 苏瑶还不知道白烬看见了什么；她的布置越细，越把截胡条件暴露给他。
