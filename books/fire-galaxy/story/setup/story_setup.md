# 虫巢远征

## Story Setup

### Genre(s)
- 科幻
- 废土
- 机甲
- 末世


### Core Premise
百年前外星虫族突袭地球，人类文明崩溃，残存的幸存者躲入地下据点苟活。21世纪的航天机甲工程师林野在实验事故中被意外封入休眠仓，百年后苏醒在被虫族完全占领的地表，同时激活了绑定自身基因的古人类终极遗产「火种机甲」与基因进化系统。他需要在虫族的围剿中求生，集结散落的人类幸存者，破解虫族入侵的真相，最终带领人类夺回母星、远征星际。

### Theme
探讨绝境下文明存续的价值与意义，展现普通人在末日重压下的成长与担当，反思人类过往发展路径对未来的影响，歌颂集体抗争、永不言弃的人类精神。

### Story Rules/Constraints
- 虫族核心母巢会释放全域电磁干扰波，压制所有非基因绑定的人类电子设备，只有适配了基因进化者的火种机甲可不受干扰正常运行
- 基因进化等级越高，可解锁的机甲权限越强，每次升级需要吸收对应等级的虫族核心能量晶核，进化时基因稳定性低于60%即触发崩溃风险，可通过特制基因抑制剂、同伴精神引导等方式降低崩溃概率
- 半人半虫异变者分为两类，一类完全丧失理智沦为虫族附庸，另一类保留人类理智可作为中立角色、可招募同伴或者亦正亦邪的反派
- 虫族种群层级严格，低级晶核对应工虫、作战兵虫，每10只兵虫约产出1枚可用低级晶核；中级晶核对应初级虫将，每百只规模虫群才配置1名初级虫将；高级晶核对应高级虫统领，全星球虫族仅不超过10名，母巢核心晶核唯一；高级虫将拥有不亚于人类的智慧，会针对性设局围剿人类幸存者，甚至会安插内奸渗透人类据点
- 普通幸存者大多聚居在地下据点，按贡献分配生存资源，对基因进化者既敬畏又排斥，普通人可通过操作旧式防御武器、参与后勤保障为反抗军贡献力量，拥有不可替代的价值
- 火种机甲内置的文明数据库隐藏着百年前虫族入侵的完整真相与旧人类星际探索记录、外星文明坐标，只有主角的基因序列可逐层解锁相关内容


### Target Audience
18-35岁的科幻爱好者、机甲爽文读者、废土末世题材受众

### Tone/Style
热血激昂，硬核科幻，末世苍凉，爽感充足

### Narrative Tense
过去时

### POV Style
第三人称有限视角

## Storylines

### 火种远征主线
- **Type**: 主线剧情
- **Importance**: 10/10
- **Description**: 主角苏醒后从最初的荒骨台荒野求生、激活基础机甲功能起步，在引路人老周的帮助下逐步找到散落的人类幸存者据点，整合各方资源与战力，一边对抗虫族的周期性围剿一边提升自身基因等级，最终集结足够的力量反攻位于青藏高原腹地的虫族母巢，成功夺回地球后带领人类走向星际探索的新征程。

### 历史真相支线
- **Type**: 悬念支线
- **Importance**: 8/10
- **Description**: 主角在解锁火种机甲数据库的过程中，逐步发现百年前虫族入侵并非偶然事件，而是当时的人类高层为了获取外星技术，与外星文明交易失控导致的灾难。如今当年背叛人类的高层后代以沈明哲为首，掌控着旧人类遗留的部分科技资源，控制着最大的幸存者据点磐石堡，他们认为普通人类基因低劣不配继承文明遗产，只有他们的「优质基因」才有资格掌控火种机甲与外星技术，因此不惜联合虫族阻挠主角，企图独占文明遗产。

### 势力整合支线
- **Type**: 成长支线
- **Importance**: 7/10
- **Description**: 不同区域的幸存者据点之间存在理念冲突、资源矛盾，甚至长期互相掠夺，主角需要在虫族的外部压力下周旋各方势力，化解内部斗争，联合保留理智的半人半虫异能者等边缘力量，建立统一的人类反抗联盟，同时培养新一代的基因进化者与机甲驾驶员，为最终的远征储备力量。


## Premises

### 基因进化与火种机甲体系 (能力成长体系)
该体系是百年前人类秘密研发的终极作战系统，只有适配特定基因序列的人才可以激活，基因进化等级与机甲的权限直接绑定，升级需要吸收对应等级的虫族能量晶核作为原料，同时使用者需要对抗虫族基因带来的污染副作用，一旦失控就会异变成半人半虫的怪物。火种机甲内置的文明数据库还预埋了旧人类星际探索记录、当年与人类交易的外星文明坐标，该外星文明仍在窥视银河系，为后续星际远征埋下冲突伏笔。

**Progression System:**

**Level 1: 基因适配者**
- Description: 刚激活系统的初级状态，可操控基础形态的火种机甲，身体素质是普通人类的3倍，可对抗最低级的工虫
- Requirements: 首次接触虫族低级晶核，完成基础基因适配

**Level 2: 基因强化者**
- Description: 可解锁机甲的近战、远程武器模块，身体素质提升至普通人类的10倍，能独立对抗虫族的作战兵虫
- Requirements: 吸收10枚低级虫族晶核，基因稳定性达到70%以上

**Level 3: 基因觉醒者**
- Description: 可解锁机甲的飞行、能量护盾模块，拥有专属的基因异能，能独立对抗中级虫族与初级虫将
- Requirements: 吸收1枚中级虫族晶核，扛过基因崩溃的风险

**Level 4: 基因掌控者**
- Description: 可解锁机甲的星际航行模块，能号令其他低等级进化者，可对抗虫族的高级统领
- Requirements: 吸收3枚高级虫族晶核，完全融合火种系统的核心代码

**Level 5: 文明火种者**
- Description: 可激活机甲的终极星舰形态，拥有改写人类基因序列的能力，是整个人类文明的法定领袖
- Requirements: 吸收虫族母巢的唯一核心晶核，解锁全部文明数据库
