# 虫巢远征

## Story Setup

### Genre(s)
- 科幻
- 废土
- 机甲
- 末世


### Core Premise
公元2140年，父母早年在外星碎片撞击事故中牺牲、出身军工世家的火种机甲项目核心研发工程师林野，在测试机甲核心基因锁模块时遭投资方沈氏家族暗害发生爆炸，被紧急封入休眠仓保存。9年后外星虫族突袭地球，人类高层勾结第三方收割者文明的交易失控，全球文明崩溃，残存幸存者躲入地下据点苟活。百年后的公元2249年，林野苏醒在被虫族完全占领的地表荒骨台，激活了自己当年预埋基因锁的古人类终极遗产「火种机甲」与基因进化系统，作为唯一能解锁机甲全权限的人，他需要在虫族围剿中求生，集结散落的人类幸存者，破解虫族入侵与当年遇袭的双重真相，最终带领人类夺回母星、远征星际。

### Theme
探讨绝境下文明存续的价值与意义，展现普通人在末日重压下的成长与担当，反思人类过往发展路径对未来的影响，歌颂集体抗争、永不言弃的人类精神。

### Story Rules/Constraints
- 虫族核心母巢会释放全域电磁干扰波，压制所有非基因绑定的人类电子设备，只有适配了基因进化系统的火种机甲可不受干扰正常运行；幸存者据点的旧式防御武器均为纯机械结构，无电子控制模块，因此也不受电磁干扰影响，普通人可正常操作，该类武器可有效杀伤工虫、作战兵虫，对初级虫将仅能造成轻伤，无法伤害中级以上虫族，战力边界清晰。
- 火种机甲的最高权限基因锁由林野当年亲自预埋，他是唯一的全权限适配者；除他之外全球仅有不超过5名次一级基因适配者，最高仅能升级至基因等级3级，无法解锁星际航行等高级权限，也无法激活机甲核心数据库；简化版火种机甲移除了核心数据库与星际航行模块，仅保留基础作战功能，采用次一级基因适配者的基因片段做绑定锁，不受电磁干扰，战力仅为完整版火种机甲的30%，无法升级至更高权限；沈明哲家族当年仅为项目投资方，未掌握核心基因编码技术，因此无法激活机甲核心功能。
- 基因进化等级越高，可解锁的机甲权限越强，每次升级除需要吸收对应等级的虫族核心能量晶核外，还需解锁一段林野当年研发火种机甲的记忆碎片，逐步揭开当年爆炸事故的真相；进化时基因稳定性低于60%即触发崩溃风险，可通过特制基因抑制剂、同伴精神引导等方式降低崩溃概率。
- 半人半虫异变者的判定标准为异变时基因稳定性是否高于40%：高于40%可保留人类理智，拥有专属异能，可免疫虫族低阶精神干扰，能在虫族领地内隐蔽活动，还可感知10公里范围内的虫族晶核与虫群动向，是反抗军勘探、渗透行动的核心力量，但因携带不可清除的虫族基因片段，无法适配火种机甲的纯人类基因锁；保留理智的异变者可通过吸收虫族晶核提升异能等级，最高可达到对应虫族初级虫将的战力，异能类型与异变时融合的虫族基因类型绑定，比如融合工虫基因的异变者拥有巨力，融合飞虫基因的异变者拥有短距离飞行能力；低于40%则完全沦为虫族附庸，无自主意识。各幸存者据点均配备基于纯机械原理的基因稳定性检测仪，可在10秒内测出异变者的基因稳定性数值；同时保留理智的异变者瞳孔为淡蓝色，失控异变者瞳孔为深黑色，可通过外观快速初步判定阵营。
- 虫族种群层级严格，低级晶核对应工虫、作战兵虫，每10只兵虫约产出1枚可用低级晶核；中级晶核对应初级虫将，每百只规模虫群才配置1名初级虫将；高级晶核对应高级虫统领，全星球虫族仅不超过10名，母巢核心晶核唯一；高级虫将拥有不亚于人类的智慧，会针对性设局围剿人类幸存者，甚至会安插内奸渗透人类据点。
- 普通幸存者大多聚居在青藤据点、磐石堡等地下据点，按贡献分配生存资源，对基因进化者既敬畏又排斥，普通人除可操作旧式防御武器、参与后勤保障外，旧文明数据芯片的修复、基因抑制剂的生产、简化版火种机甲的维护都需要普通科研人员、技术工人的参与，仅靠基因进化者无法完成，拥有不可替代的价值。
- 火种机甲内置的文明数据库隐藏着百年前虫族入侵的完整真相与旧人类星际探索记录、外星文明坐标，只有林野的基因序列可逐层解锁相关内容；旧文明数据芯片的解锁与林野的基因等级绑定，低级芯片可在基因等级1-2级时解锁基础生产技术，高级芯片需要基因等级3级以上才能解锁武器、机甲相关的额外功能。林野当年研发火种机甲时，同步为旧人类文明备份芯片设置了配套的基因权限锁，避免核心科技落入敌对势力手中，因此只有对应基因等级的权限才能解锁对应芯片内容。
- 沈明哲集团掌握虫族需要的旧人类隐蔽星际星舰坐标数据，该坐标为分段加密格式，只有凑齐9枚散落在不同旧人类遗址的密钥才能完全解锁，沈氏百年间仅找到3枚，因此迟迟无法完成与虫族的交易；沈氏以此为筹码与虫族高级统领达成交易：虫族承诺给予沈明哲及其300名核心成员「虫族基因改造豁免权」，允许他们保留人类意识并获得10%的地球统治权，虫族拿到完整星舰坐标后将前往银河系扩张，不会销毁沈明哲集团核心成员的人类基因，因此不会主动攻击沈明哲的势力。虫族高层受制于当年撮合交易的第三方外星文明协议，必须履行与沈氏的交易，否则会被剥夺族群进化资格；沈氏家族在大陨落后依托留存的军工资源建立了磐石堡据点，逐步垄断基因抑制剂的生产与销售，借此巩固了百年统治地位。
- 撮合沈氏与虫族交易的第三方外星文明名为「收割者文明」，以诱导低等文明内斗、收割文明成果为生存方式，当年和人类高层交易的条件是用虫族技术换取地球生物基因库，交易失控后仍在暗中观察虫族与人类的战争，准备收割最终胜利者的文明成果，是贯穿整个故事的最终反派势力。

## Storylines

### 第一章：荒骨苏醒
- **Type**: 开篇章节
- **Importance**: 9/10
- **Description**: 林野在冰冷的休眠仓中苏醒，周围是荒骨台废弃的机甲测试场残骸与虫族工虫的嘶吼声，他靠着残存的记忆激活了埋在测试场地下的火种机甲核心，艰难击退3只工虫后体力不支晕倒在地，被外出勘探的青藤据点人员发现带回。

### 火种远征主线
- **Type**: 主线剧情
- **Importance**: 10/10
- **Description**: 性格沉稳务实、重情重义、有着极强责任感的林野被外出勘探的青藤据点武器维护师老周（旧时代军工世家后人，林野苏醒后的引路人）、护卫队长苏晴救回据点后，逐步了解百年间的世界变化。他最初的诉求是查清当年被沈氏暗害的事故真相、为死去的父母与同事复仇，在目睹幸存者的生存惨状后转变为带领全人类争夺生存权的信念，之后一边对抗虫族的周期性围剿一边提升自身基因等级，与次一级基因适配者苏晴等同伴一起整合各方资源与战力，最终集结足够的力量反攻位于青藏高原腹地的虫族母巢，成功夺回地球后带领人类走向星际探索的新征程。

### 历史真相支线
- **Type**: 悬念支线
- **Importance**: 8/10
- **Description**: 林野在解锁火种机甲数据库、唤醒研发记忆碎片的过程中，逐步发现百年前虫族入侵并非偶然事件，而是当时的人类高层为了获取外星技术，与收割者文明交易失控导致的灾难。如今当年背叛人类的高层后代、42岁的沈明哲作为沈氏家族现任家主，掌控着旧人类遗留的部分科技资源，控制着最大的幸存者据点磐石堡，他们认为普通人类基因低劣不配继承文明遗产，只有他们的「优质基因」才有资格掌控火种机甲与外星技术，因此不惜联合虫族阻挠林野，企图独占文明遗产。

### 势力整合支线
- **Type**: 成长支线
- **Importance**: 7/10
- **Description**: 不同区域的幸存者据点之间存在理念冲突、资源矛盾，甚至长期互相掠夺，林野需要在虫族的外部压力下周旋各方势力，化解内部斗争，联合以异变者首领阿蝉为代表的保留理智的半人半虫异能者等边缘力量，建立统一的人类反抗联盟，同时培养次一级的基因适配者驾驶简化版火种机甲，为最终的远征储备力量。


## Premises

### 基因进化与火种机甲体系 (能力成长体系)
该体系是百年前人类秘密研发的终极作战系统，只有适配特定基因序列的人才可以激活，基因进化等级与机甲的权限直接绑定，升级需要吸收对应等级的虫族能量晶核作为原料，同时使用者需要对抗虫族基因带来的污染副作用，一旦失控就会异变成半人半虫的怪物。除唯一全权限适配者林野外，其余次一级适配者最高仅能升级至基因等级3级，无法解锁高级权限。火种机甲内置的文明数据库还预埋了旧人类星际探索记录、当年与人类交易的收割者文明坐标，该外星文明仍在窥视银河系，为后续星际远征埋下冲突伏笔。

**Progression System:**

**Level 1: 基因适配者**
- Description: 刚激活系统的初级状态，可操控基础形态的火种机甲，身体素质是普通人类的3倍，可对抗最低级的工虫
- Requirements: 首次接触虫族低级晶核，完成基础基因适配，解锁第一次组装火种机甲核心的记忆碎片

**Level 2: 基因强化者**
- Description: 可解锁机甲的近战、远程武器模块，身体素质提升至普通人类的10倍，能独立对抗虫族的作战兵虫
- Requirements: 吸收10枚低级虫族晶核，基因稳定性达到70%以上，解锁基因锁模块研发的记忆碎片

**Level 3: 基因觉醒者**
- Description: 可解锁机甲的飞行、能量护盾模块，拥有专属的基因异能，能独立对抗中级虫族与初级虫将，也是次一级基因适配者可达到的最高等级
- Requirements: 吸收1枚中级虫族晶核，扛过基因崩溃的风险，解锁机甲武器模块测试的记忆碎片

**Level 4: 基因掌控者**
- Description: 仅林野可达到的等级，可解锁机甲的星际航行模块，可通过火种机甲的基因链共振向所有适配基因进化系统的用户发送全域加密信息、共享虫群动向数据，该传输不属于电磁波频段，不受虫族电磁干扰影响，仅适配了基因进化系统的用户可接收，获得进化者的天然信服，可对抗虫族的高级统领
- Requirements: 吸收3枚高级虫族晶核，完全融合火种系统的核心代码，解锁当年爆炸事故前的最后一段工作记忆碎片

**Level 5: 文明火种者**
- Description: 仅林野可达到的等级，可激活机甲的终极星舰形态，仅可修复全人类被虫族基因长期辐射导致的基因退化、生育率下降缺陷，无法修改或强化正常人类基因，使用该能力需消耗母巢核心晶核90%的能量，仅能使用一次，是整个人类文明的法定领袖
- Requirements: 吸收虫族母巢的唯一核心晶核，解锁全部文明数据库，解锁当年被暗害的完整真相记忆碎片
