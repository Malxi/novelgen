# 星骸火种

## Story Setup

### Genre(s)
- 科幻
- 废土
- 机甲
- 末世


### Core Premise
公元2140年，出身军工世家、父母早年牺牲于外星碎片撞击事故的火种机甲项目核心研发工程师林野，性格沉稳务实、重情重义，在测试机甲核心基因锁模块时遭投资方沈氏家族暗害发生爆炸，被紧急封入休眠仓送往秘密基地保存。2149年外星虫族突袭地球，人类高层勾结第三方收割者文明的交易失控，全球文明崩溃，残存幸存者躲入地下据点苟活。百年后的公元2249年，荒骨台区域地质活动暴露了掩埋的休眠仓，林野苏醒后激活了自己当年预埋基因锁的古人类终极遗产「火种机甲」与基因进化系统。作为唯一能解锁机甲全权限的人，他最初的诉求是查清当年遇袭真相为亲友复仇，在目睹幸存者的生存惨状后转变为带领人类争夺生存权的信念，需要在虫族围剿中求生，集结散落的人类幸存者，破解虫族入侵与当年遇袭的双重真相，最终带领人类夺回母星、对抗收割者文明的星际威胁。

### Theme
探讨绝境下文明存续的价值与意义，展现普通人在末日重压下的成长与担当，反思人类过往发展路径对未来的影响，歌颂集体抗争、永不言弃的人类精神。

### Story Rules/Constraints
- 虫族核心母巢会释放全域电磁干扰波，压制所有非基因绑定的人类电子设备，只有适配了基因进化系统的火种机甲可不受干扰正常运行；大陨落前人类已经预判到电磁攻击风险，提前在各地下据点储备了大量纯机械武器的生产图纸与原料，百年间幸存者可以自行生产维护这类无电子控制模块的旧式防御武器，普通人可正常操作，该类武器可有效杀伤工虫、作战兵虫，对初级虫将仅能造成轻伤，无法伤害中级以上虫族，战力边界清晰。
- 火种机甲的最高权限基因锁由林野当年亲自预埋，他是唯一的全权限适配者；除他之外全球仅有不超过5名次一级基因适配者，最高仅能升级至基因等级3级，无法解锁星际航行等高级权限，也无法激活机甲核心数据库；次一级基因适配者升级时不会解锁林野的研发记忆碎片，但会触发自身的基因潜能觉醒，解锁专属的个人异能，可适配简化版火种机甲的额外功能，拥有独立成长路径；全球现存的5名次一级基因适配者中，2名属于沈氏核心成员，1名是独立游走的赏金猎人，1名是异变者阵营的隐藏适配者（该隐藏适配者是异变者首领阿蝉的义兄，十年前为掩护异变者族群撤退被沈氏俘虏，目前被关押在磐石堡地下实验室，为后续营救支线预埋钩子），1名是青藤据点护卫队长苏晴，为后续势力合纵连横预留剧情空间。
- 简化版火种机甲移除了核心数据库与星际航行模块，仅保留基础作战功能，采用次一级基因适配者的基因片段做绑定锁，不受电磁干扰，战力仅为完整版火种机甲的30%，无法升级至更高权限；沈氏百年间仅掌握简化版火种机甲的组装技术，但缺少核心基因编码模块，百年间仅组装出不到10台供家族核心成员使用，批量生产技术只有林野解锁三级基因权限后才能从文明数据库中获取；沈明哲家族当年仅为项目投资方，未掌握核心基因编码技术，因此无法激活机甲核心功能。
- 主角成长采用“火种机甲形态/模块”为显性升级主轴，“基因适配/稳定性”为权限钥匙与代价副轴：机甲每次升级必须同时满足模块蓝图、能量核心、战场实测三类条件，基因等级只决定林野能否承受更高权限与更强神经同步，不能单独带来无成本战力暴涨；基因稳定性低于60%即触发反噬风险，可通过基因抑制剂、同伴精神引导、机甲冷却休眠降低风险。
- 半人半虫异变者的判定标准为异变时基因稳定性是否高于40%：高于40%可保留人类理智，拥有专属异能，可免疫虫族低阶精神干扰，能在虫族领地内隐蔽活动，还可感知10公里范围内的虫族晶核与虫群动向，是反抗军勘探、渗透行动的核心力量；异变者携带的虫族基因片段已整合到人类核心基因链中，即使是5级林野的基因修复波也无法清除，仅能抑制其异变倾向，无法使其适配火种机甲的纯人类基因锁；保留理智的异变者人类基因占比普遍在70%以上，可适配仅要求人类基因占比高于60%的简化版火种机甲基因锁，仅无法适配完整版火种机甲的纯人类基因锁；保留理智的异变者因携带虫族基因片段，低阶虫族不会主动对其发起攻击，但中级以上虫将可通过精神波动识别其人类意识身份，会主动发起围剿，既强化异变者的渗透优势，也明确其生存风险；保留理智的异变者可通过吸收虫族晶核提升异能等级，最高可达到对应虫族初级虫将的战力，异能类型与异变时融合的虫族基因类型绑定，比如融合工虫基因的异变者拥有巨力，融合飞虫基因的异变者拥有短距离飞行能力；低于40%则完全沦为虫族附庸，无自主意识。各幸存者据点均配备基于纯机械原理的基因稳定性检测仪，可在10秒内测出异变者的基因稳定性数值；同时保留理智的异变者瞳孔为淡蓝色，失控异变者瞳孔为深黑色，可通过外观快速初步判定阵营。
- 虫族种群层级严格，低级晶核对应工虫、作战兵虫，每10只兵虫约产出1枚可用低级晶核；中级晶核对应初级虫将，每百只规模虫群才配置1名初级虫将；高级晶核对应高级虫统领，全星球虫族仅不超过10名，母巢核心晶核唯一；高级虫将拥有不亚于人类的智慧，会针对性设局围剿人类幸存者，甚至会安插内奸渗透人类据点。
- 普通幸存者大多聚居在青藤据点、磐石堡、黄土沟据点等地下据点，按贡献分配生存资源，对基因进化者既敬畏又排斥，普通人除可操作旧式防御武器、参与后勤保障外，旧文明数据芯片的修复、基因抑制剂的生产、简化版火种机甲的维护都需要普通科研人员、技术工人的参与，仅靠基因进化者无法完成，拥有不可替代的价值；普通技工老周将在最终母巢决战时，靠纯机械技术临时修复火种机甲的能量管路，为林野争取到吸收母巢晶核的关键10分钟，凸显普通人的不可替代性。
- 火种机甲内置的文明数据库隐藏着百年前虫族入侵的完整真相与旧人类星际探索记录、外星文明坐标，只有林野的基因序列可逐层解锁相关内容；旧文明数据芯片的解锁与林野的基因等级绑定，低级芯片可在基因等级1-2级时解锁基础生产技术，高级芯片需要基因等级3级以上才能解锁武器、机甲相关的额外功能。林野当年研发火种机甲时，同步为旧人类文明备份芯片设置了配套的基因权限锁，避免核心科技落入敌对势力手中，因此只有对应基因等级的权限才能解锁对应芯片内容。
- 沈明哲集团掌握虫族需要的旧人类隐蔽星际星舰坐标数据，该坐标为分段加密格式，9枚密钥是当年沈氏家族参与火种机甲项目时，为保管旧人类星际星舰坐标专门定制的基因绑定存储介质，仅沈氏直系后代的基因可激活感应；9枚密钥分别散落在虫族高级统领的领地、旧人类核心军事禁区（设有纯机械触发的自毁装置，非沈氏基因携带者靠近直接引爆）等极高风险区域，沈氏百年间多次派人搜寻损失惨重，因此仅找到3枚，迟迟无法完成与虫族的交易；沈氏与虫族高级统领的正式交易为近10年才达成，此前百年间双方处于敌对状态，且交易豁免权仅覆盖沈氏登记在册的300名核心成员，外围成员不受保护，低阶虫族未收到指令时也可能误攻外围人员，因此沈氏百年间有上千成员死于虫族突袭，当代家主沈明哲的妻儿也因此丧生；沈氏以此为筹码与虫族高级统领达成交易：虫族承诺给予沈明哲及其300名核心成员「虫族基因改造豁免权」，允许他们保留人类意识并获得10%的地球统治权，虫族拿到完整星舰坐标后将前往银河系扩张，不会销毁沈明哲集团核心成员的人类基因，因此不会主动攻击沈明哲的势力。该交易背后有两条强制规则支撑：一是收割者文明给虫族高层下了精神契约，伤害沈氏核心成员会直接触发精神爆亡；二是9枚密钥只有沈氏家族的基因序列可以感应定位，虫族无法自行搜寻，因此必须和沈氏合作；沈明哲认为普通人类根本不可能对抗虫族，只有通过和虫族交易保留精英火种，后续得知收割者文明收割所有文明成果的终极阴谋后可临阵倒戈，并非纯粹的邪恶反派；沈氏家族在大陨落后依托留存的军工资源建立了磐石堡据点，逐步垄断基因抑制剂的生产与销售，借此巩固了百年统治地位。补充精神契约约束范围：仅禁止虫族主动攻击沈氏登记在册的300名核心成员，沈氏主动攻击虫族时契约不生效；且契约仅在地球大气层范围内有效，离开地球后自动失效，为后续星际剧情中沈氏临阵倒戈预埋伏笔。
- 撮合沈氏与虫族交易的第三方外星文明名为「收割者文明」，以诱导低等文明内斗、收割文明成果为生存方式，当年和人类高层交易的条件是用虫族技术换取地球生物基因库，交易失控后仍在暗中观察虫族与人类的战争，在虫族与人类阵营都安插了卧底，会不定期给弱势一方提供技术支持，刻意维持双方战力平衡，方便最终收割胜利方的文明成果，其已在太阳系外围布置了收割舰队，待地球战局明朗后就会发起入侵，是贯穿整个故事的最终反派势力；收割者文明单舰战力相当于初级虫将，主力舰战力相当于高级虫统领，收割舰队总战力相当于1.5倍虫族全族战力，林野达到5级后联合全人类战力+虫族残余势力（虫族母巢被毁后残余虫群不愿被收割，会选择和人类临时结盟）可与之对抗，战力边界清晰无后期崩盘风险。

### 荒骨苏醒
- **Type**: 开篇弧线
- **Importance**: 9/10
- **Scope**: opening
- **Payoff Style**: immediate
- **Setup Role**: 生存钩子与能力开启
- **Description**: 公元2249年荒骨台突发地质活动，掩埋百年的休眠仓被掀出地表，林野在冰冷中苏醒，周围是废弃机甲测试场残骸与虫族嘶吼。他激活火种机甲核心与配套的纯机械动力3D打印设备，利用废墟金属打印零件，在工虫合围前完成基础部件，首次基因适配卡在临界值，击退工虫后晕倒，被青藤据点勘探队发现带回。此弧线奠定林野的危机处境，引出火种机甲的基本设定与基因适配代价，同时埋下青藤据点为后续盟友的伏笔。
- **Desire**: 林野苏醒后第一要务是活下去，搞清楚自己身处的环境与时间
- **Opposition**: 周围游荡的虫族工虫、首次基因适配带来的反噬风险
- **Stakes**: 一旦死在这里，人类唯一的全权限机甲适配者就会消失，文明再无翻盘可能
- **Open Question**: 百年间到底发生了什么，为什么曾经的机甲测试场变成了虫族活动的荒地
- **Pressure Points**: 工虫合围的紧迫时间线; 基因稳定性临界值的反噬威胁; 休眠仓能量耗尽后低体温症的生理危机; 被青藤据点探测仪发现虫族基因波动可能招致排斥

- **Setup Role**: 平行阵营整合
- **Description**: 各幸存者据点之间存在理念冲突与资源矛盾，甚至互相掠夺。林野在虫族压力下周旋各方，化解内部斗争，联合异变者等边缘力量，建立统一反抗联盟，培养次一级基因适配者驾驶简化版火种机甲，为反攻储备力量。
- **Desire**: 林野要整合所有人类势力，建立统一的反抗联盟，积蓄反攻虫族的足够力量
- **Opposition**: 各据点之间的历史旧怨、资源分配矛盾、普通人类与异变者的信任裂痕
- **Payoff**: 建立跨阵营的统一反抗联盟，集齐所有可以团结的力量，为反攻母巢做好充分准备
- **Pressure Points**: 磐石堡沈氏对其他据点的资源封锁; 虫潮压力下部分据点为了生存互相掠夺; 普通幸存者对异变者阵营的排斥情绪; 营救被沈氏关押的异变者隐藏适配者的紧急需求


## Premises

### 火种机甲形态与模块解锁体系 (主角机甲升级体系)
主角最显性的升级体系。火种机甲不是单纯随基因等级变强，而是通过回收旧文明模块、修复核心蓝图、吸收对应晶核能量，并完成实战校准逐步解锁形态。每一形态都对应新的战斗方式与剧情用途，同时有明确能耗、冷却或维修代价。

**Progression System:**

**Level 1: 残骸外骨骼**
- Description: 利用测试场纯机械打印设备拼出半开放式外骨骼，只能提供短时力量增幅与基础防护，适合开篇逃生和击退工虫。
- Requirements: 火种核心苏醒；测试场残骸金属；1枚低级虫族晶核启动；连续作战不超过15分钟，否则关节过热锁死。

**Level 2: 基础火种甲**
- Description: 完成躯干装甲、神经同步和基础近战模块，能稳定对抗工虫与少量兵虫，首次形成“主角有机甲”的核心爽点。
- Requirements: 林野基因适配1级；完成基础装甲蓝图修复；消耗10枚低级晶核或等价能源；需要老周完成机械校准。

**Level 3: 武装集成甲**
- Description: 解锁腕刃、肩炮、短距推进和战场扫描模块，战斗风格从硬扛转向机动压制，可单挑作战兵虫小队。
- Requirements: 林野基因适配2级；回收旧文明武器芯片；完成一次虫潮实战数据采样；每次重火力齐射会快速消耗核心能量。

**Level 4: 空战护盾甲**
- Description: 解锁短时飞行、能量护盾和空中姿态控制，能与初级虫将正面对抗，也是中期大战的视觉升级节点。
- Requirements: 林野基因适配3级；1枚中级虫族晶核；修复飞行模块蓝图；基因稳定性低于75%时禁止连续飞行。

**Level 5: 指挥链路甲**
- Description: 机甲成为移动指挥中枢，可通过非电磁基因链路同步友军位置、虫群动向和简化机甲状态，主角从单兵王牌升级为战场核心。
- Requirements: 林野基因适配4级；完成火种核心代码融合；至少三个据点接入有线/机械信标；链路开启时林野精神负荷剧增。

**Level 6: 星舰核心甲**
- Description: 机甲从地面战斗平台升级为小型星舰核心，可启动轨道突入、深空导航和高能主炮，但维护消耗巨大。
- Requirements: 解锁旧文明星航数据库；获得高级虫族晶核3枚；修复星际航行模块；启动后需至少一个据点工业体系供养维修。

**Level 7: 文明火种甲**
- Description: 终极形态，释放全球级基因修复波并承载人类文明数据库，可作为新文明旗舰中枢。使用后机甲一年内无法星际航行，避免终局能力滥用。
- Requirements: 吸收虫族母巢核心晶核；林野基因适配5级；解锁全部文明数据库；只能使用一次全球修复波。


### 林野基因适配与稳定性体系 (主角基因权限体系)
基因不是主角的主要视觉爽点，而是火种机甲权限、神经同步和反噬风险的底层钥匙。等级越高，林野能承受的机甲形态越强，但每次突破都必须面对虫族基因污染、记忆碎片冲击和稳定性阈值，保证成长有代价。

**Progression System:**

**Level 1: 基因适配者**
- Description: 完成火种核心的初始绑定，可操控残骸外骨骼与基础火种甲，身体素质提升但仍会出现反噬眩晕。
- Requirements: 首次吸收低级晶核；基因稳定性保持60%以上；解锁第一段研发记忆碎片。

**Level 2: 基因强化者**
- Description: 神经同步速度提升，能承受武装集成甲的多模块并行，身体素质约为普通人的10倍。
- Requirements: 吸收10枚低级晶核；基因稳定性达到70%以上；获得基因抑制剂辅助。

**Level 3: 基因觉醒者**
- Description: 觉醒林野专属的机甲共鸣能力，可短时间预判机甲结构故障与敌方攻击轨迹，是空战护盾甲的最低权限。
- Requirements: 吸收1枚中级虫族晶核；扛过一次基因崩溃风险；解锁武器模块测试记忆。

**Level 4: 基因掌控者**
- Description: 可主动压制虫族基因污染，承受指挥链路甲带来的群体信息冲击，成为多据点联军的机甲指挥核心。
- Requirements: 吸收3枚高级晶核；完成火种核心代码融合；基因稳定性长期维持85%以上。

**Level 5: 文明火种者**
- Description: 纯人类基因锁完全打开，可承载文明火种甲和全球修复波，但使用终极权限会导致长时间虚弱与机甲停航。
- Requirements: 吸收虫族母巢核心晶核；解锁全部文明数据库；接受完整真相记忆冲击且保持自我。


### 火种数据库与模块蓝图体系 (主角机甲研发体系)
主角升级不只靠打怪吸晶核，还要逐步修复旧文明数据库，找到对应模块蓝图、校验权限并让据点工业能造得出来。这个体系负责把探索、解谜、据点建设和机甲升级绑在一起。

**Progression System:**

**Level 1: 残片读取**
- Description: 读取低级旧文明数据芯片，获得基础维修、金属打印和外骨骼零件图纸。
- Requirements: 旧文明数据芯片1枚；基础火种核心在线；老周或同等级技术人员协助解码。

**Level 2: 武装蓝图**
- Description: 解锁近战、肩炮、短距推进等武装模块蓝图，让机甲升级具备可制造依据。
- Requirements: 林野基因适配2级；回收军工遗址数据芯片；据点达到基础工业化。

**Level 3: 防御航行蓝图**
- Description: 解锁能量护盾、飞行控制和高负荷冷却系统，为空战护盾甲服务。
- Requirements: 林野基因适配3级；中级晶核样本；完成一次初级虫将战斗数据回灌。

**Level 4: 链路协议**
- Description: 解锁非电磁战场链路和简化机甲协同协议，让主角能指挥联军而不是只靠个人战力。
- Requirements: 林野基因适配4级；三个据点加入联军；完成沈氏简化机甲协议破解。

**Level 5: 星航核心**
- Description: 解锁星际航行、轨道突入和文明数据库全量备份，为故事后半的收割者威胁与星际远征铺路。
- Requirements: 高级旧文明数据芯片；星舰残骸或深空补给站坐标；高级虫族晶核3枚。


### 异变者异能体系 (能力成长体系)
半人半虫异变者保留人类理智后，可通过吸收虫族晶核提升异能等级，异能类型与融合的虫族基因类型绑定。最高可达初级虫将战力。异变者免疫低阶精神干扰，可感知晶核与虫群动向，是人类渗透作战的核心力量。

**Progression System:**

**Level 1: 初醒异变者**
- Description: 刚完成异变时保留理智，拥有基础异能（如巨力、短距离飞行），异变时基因稳定性需>40%。
- Requirements: 异变后基因稳定性≥70%（人类基因占比），吸收过1枚低级晶核

**Level 2: 熟练异变者**
- Description: 异能强度提升，感知范围扩大至10公里，可短时间潜入虫族领地而不被发现。
- Requirements: 吸收5枚低级晶核，基因稳定性≥75%

**Level 3: 精英异变者**
- Description: 异能可短暂对抗初级虫将，感知能力升级，能识别虫族精神干扰的来源。
- Requirements: 吸收1枚中级晶核，基因稳定性≥80%，完成至少一次渗透任务

**Level 4: 异变者统领**
- Description: 实力相当于初级虫将顶峰，可统领其他异变者，异能可产生范围效果，能短暂匹敌中级虫将。
- Requirements: 吸收3枚中级晶核，基因稳定性≥85%，得到族群认可


### 沈氏简化机甲与技术垄断体系 (技术科技体系/shen)
沈氏百年来掌握简化版火种机甲的组装技术，仅能生产10台以内，战力为完整机甲的30%，无星际功能。沈氏通过垄断基因抑制剂和蓝星草资源巩固统治。依赖9枚密钥与虫族交易，但实际控制力有限。

**Progression System:**

**Level 1: 组装调试**
- Description: 沈氏利用残存图纸和次一级适配者基因片段组装基础简化机甲，可抵御工虫。
- Requirements: 拥有次一级适配者基因样本与基础金属原料

**Level 2: 武器集成**
- Description: 为简化机甲加装远程武器系统，可对抗作战兵虫，但能耗巨大。
- Requirements: 回收旧文明军工厂残存武器模块，或从虫族战场回收完整部件

**Level 3: 能量护盾改装**
- Description: 安装初代护盾模块，可短暂抵挡初级虫将一击，但需消耗大量蓝星草提炼的稳定剂。
- Requirements: 获得至少一枚中级虫族晶核作为供能核心，突破沈氏家族内部技术封锁

**Level 4: 半智能协同**
- Description: 将简化机甲与固定据点防御系统联网（有线传输，避免电磁干扰），实现战场辅助指挥，但无法提升单机战力。
- Requirements: 林野解锁三级基因后，从文明数据库获取协同协议


### 据点资源与生产体系 (经济生产体系)
各地下据点依靠旧文明储备的纯机械武器图纸与核聚变晶块维持防御和生产。基因抑制剂由蓝星草提取，沈氏垄断。普通人与技术工人是不可替代的生产力量，能在最终决战中发挥关键作用。

**Progression System:**

**Level 1: 自给自足**
- Description: 据点能够生产基础冷兵器和简单机械防御工事，靠旧核聚变晶块供电，人口上限500人。
- Requirements: 拥有至少一套纯机械车床与旧式能源储备

**Level 2: 基础工业化**
- Description: 可批量生产旧式轻武器与简易动力装甲（非机甲），据点防御力提升，人口上限1000人。
- Requirements: 修复一座旧文明工业废墟，获得至少10枚旧文明数据芯片（低阶）

**Level 3: 晶核能源化**
- Description: 掌握利用低级虫族晶核补充据点能源的技术，延长核聚变晶块使用寿命，可支持中小型能量武器原型。
- Requirements: 猎杀足够工虫收集100枚低级晶核，并组建专门科研小队

**Level 4: 基因抑制剂量产**
- Description: 突破蓝星草种植技术（如在特定地下溶洞培育），打破沈氏垄断，使基因抑制剂成为据点可自产资源。
- Requirements: 营救被沈氏关押的生物学家，获得培育技术；或林野四级后从数据库获取替代配方

**Level 5: 跨据点贸易网络**
- Description: 建立稳定的据点间物流与信息传递体系（依赖有线电报+机械运输队），实现资源互换与联合防御。
- Requirements: 至少三个据点签署互助条约，并清除沿途虫族小型巢穴


### 虫族阶层与天敌体系 (敌对势力体系/zerg)
虫族按阶层分化，以母巢为核心，高级虫统领先知级智慧。晶核等级与阶层对应，是基因进化核心原料。母巢核心晶核唯一，吸收后可解锁5级。残余虫群在母巢毁灭后可能倒戈对抗收割者。

**Progression System:**

**Level 1: 工虫层**
- Description: 基础劳动力与炮灰，单只战力约等于普通成年人，晶核产出率10:1，无法威胁火种机甲。
- Requirements: 无（基础产兵单位）

**Level 2: 作战兵虫层**
- Description: 主战兵力，速度、力量是工虫3倍，可破开轻型防御工事。每百只兵虫配一名初级虫将。
- Requirements: 工虫消耗足够生物质后进化而来

**Level 3: 初级虫将层**
- Description: 统率百虫，拥有简单战术智慧，可干扰低级电子设备（但无法影响火种机甲）。晶核为中级。
- Requirements: 兵虫积累足够晶核能量后晋升

**Level 4: 高级虫统领层**
- Description: 全宇宙族不超过10名，智慧不亚于人类，可设局渗透。单只战力可对抗四级林野。晶核为高级。
- Requirements: 母巢赋予或吞噬多位初级虫将而成

**Level 5: 母巢**
- Description: 虫族核心，释放全域电磁干扰波，只有一颗核心晶核。摧毁母巢后虫族体系瓦解，残余虫群不再受控制，可能选择与人类结盟对抗收割者。
- Requirements: 虫族文明最高产物，需要大量生物质与能量积累数十年


### 收割者文明威胁体系 (威胁升级体系)
诱导低等文明内斗、收割文明成果的外星势力。已在太阳系外围布置舰队，战力为虫族全族的1.5倍。战斗中会向弱势方提供技术支持以维持平衡。最终需林野五级后联合人类与残余虫群方可对抗。

**Progression System:**

**Level 1: 观察诱导**
- Description: 收割者仅通过卧底和远程干扰操纵人类与虫族冲突，不直接介入。
- Requirements: 无（隐藏阶段）

**Level 2: 资源倾斜**
- Description: 当一方弱势时，收割者通过匿名信息或物资掉落给予平衡性技术支持（如给沈氏先进武器蓝图）。
- Requirements: 人类或虫族战力失衡持续3个月以上

**Level 3: 先锋入侵**
- Description: 当母巢被毁或人类取得决定性胜利时，收割者前锋舰队突入大气层，单舰战力相当于初级虫将，试探双方残余力量。
- Requirements: 地球虫族/人类某一方基本统一

**Level 4: 全面收割**
- Description: 收割者主力舰队发动总攻，主力舰战力相当于高级虫统领，总战力1.5倍虫族。需要林野5级机甲+全人类联军+残余虫群联合对抗。
- Requirements: 先锋探测到地球文明剩余战力不足以威胁收割者

**Level 5: 文明重组**
- Description: 如果联军获胜，收割者被击退或消灭，人类获得外星科技碎片，开启星际探索时代。若失败则文明被归档抹除。
- Requirements: 联军打赢全面收割战役
