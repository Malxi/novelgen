# Story Outline

## 荒骨之火

**Summary:** 林野在荒骨台苏醒后激活火种机甲，被青藤据点收留，逐步了解百年后的废土世界。他依靠火种机甲击退虫群、获得据点信任，并开始探寻当年遇袭的真相。与此同时，沈氏家族与虫族的隐秘交易逐渐浮出水面，异变者阵营和次一级适配者的线索接连出现，人类存续的希望与内部暗流同时涌动。

### 第一卷：苏醒与立足

**Summary:** 公元2249年，荒骨台地质活动暴露了林野的休眠仓。苏醒后他激活了火种机甲核心与纯机械3D打印设备，艰难击退工虫后因基因反噬昏迷，被青藤据点勘探队救回。据点内，老周组装好基础版机甲，林野凭借击退小规模虫群的战绩获得信任，同时从苏晴和老周口中了解到百年来人类苟延残喘的现状。他决心先站稳脚跟，再查清当年遇袭的真相。

**Payoff Contract:**
- **Volume Question:** 苏醒于百年废土的林野，能否在虫族环伺的绝境中激活火种机甲、获得青藤据点信任，并揭开百年前遇袭的第一层真相？
- **Power Promise:** 火种核心从残骸外骨骼到基础火种甲逐步成形，展示基因适配、机械打印和旧文明技术回收带来的成长路径。
- **Main Opponent Misread:** 沈氏与虫族情报网以为火种核心只是旧时代遗物，低估林野能用纯机械技术重新点燃它。
- **Big Win:** 林野激活火种核心，击退虫群赢得据点初步信任，回收旧文明芯片与大型维修系统，并推动据点自产基因抑制剂和能量晶粒。
- **Visible Reward:** 基础火种甲、旧文明数据芯片、纯机械维修系统、自产基因抑制剂、能量晶粒和远征情报。
- **Reputation Shift:** 林野从来历不明的危险外来者，变成青藤据点核心成员眼中的战斗力和科技突破希望。
- **Next Bigger Game:** 东部核子研究所的星际坐标密钥线索浮出水面，沈氏情报网也开始追猎火种核心。

#### 荒骨苏醒

**Summary:** 林野在荒骨台地质活动暴露的休眠仓中苏醒，激活火种机甲核心与纯机械3D打印设备，击退三只工虫后因首次基因适配的反噬而昏迷，被青藤据点勘探队发现带回

**Characters:** 林野

**Location:** 荒骨台废弃机甲测试场

**Events:**
- **林野** → wake → 林野 (state) @ 荒骨台废弃机甲测试场 | 林野在百年后的废土醒来，发现自己被埋藏了整整一个世纪
- **林野** → discover → 火种核心与纯机械3D打印设备 (item) @ 地下维修通道 | 林野获得火种核心与基础外骨骼的制造条件——这是百年后人类文明复苏的第一把钥匙。握着熟悉的金属零件，百年前的研发记忆碎片涌上心头，他既为火种核心仍在运转而庆幸，又为物是人非的苍凉感到刺痛
- **林野** → upgrade → 残骸外骨骼形态 (state) @ 地下维修通道 | 火种核心拥有了第一套可用外骨骼载体，林野具备了基本的自保战力
- **林野** → calibrate → 火种核心校准数据 (state) @ 首次适配 | 林野能短时间操控火种核心，但反噬风险仍然存在——基因适配的代价首次浮现
- **林野** → afflict → 基因适配反噬 (state) @ 虫族袭击后 | 林野因基因反噬昏迷被青藤据点勘探队发现并带回据点

**Beats:**
1. 从破损的休眠仓中爬出，发现周围是陌生的荒漠废土，视线可及处有倒塌的钢筋混凝土建筑残骸
2. 回忆碎片闪过：测试场爆炸、最信任的副手赵明的脸，但理不清脉络
3. 挤入半坍楼梯进入地下维修通道，找到尘封的银色菱形金属舱体，回忆百年前预埋时的操作流程，手动输入三组基因编码激活核心
4. 发现旁边的纯机械3D打印设备，手动装入原料、启动打印程序，耗时15分钟完成基础外骨骼零件生产，消耗1枚核心预埋的低级虫族晶核
5. 基础外骨骼机甲穿在身上，核心预埋的虫族晶核能量自动注入体内，完成一级基因适配，身体机能短暂提升至人类3倍
6. 三只工虫堵住入口，林野使用热能短剑艰难击退三只虫族，但能量耗尽后出现基因反噬疼痛，失去意识倒地

**Opening Beat:** 从破损的休眠仓中爬出，发现周围是陌生的荒漠废土，视线可及处有倒塌的钢筋混凝土建筑残骸

**Closing Beat:** 三只工虫堵住入口，林野使用热能短剑艰难击退三只虫族，但能量耗尽后出现基因反噬疼痛，失去意识倒地

**State Change:** 林野在废土苏醒，激活火种核心与残骸外骨骼，击退虫族后因基因反噬昏迷，被青藤据点勘探队发现

**Chapter Payoff:**
- **Desire:** 从休眠仓脱困，激活火种核心自保
- **Pressure:** 虫族工虫就在周围，手无寸铁必死无疑
- **Clever Move:** 利用地下维修通道的3D打印设备，用废墟金属打印残骸外骨骼零件
- **Payoff Moment:** 残骸外骨骼组装完成，热能短剑斩击工虫的首次战斗画面
- **Reward:** 获得火种核心激活权限，解锁残骸外骨骼形态
- **Social Proof:** 独自一人无社交反馈
- **Hook:** 基因反噬昏迷，被未知勘探队带走

**Storyline Advances:**
- **荒骨苏醒** (hook): 林野苏醒了，火种核心已激活，残骸外骨骼形态首次亮相 | consequence: 青藤据点勘探队发现了他，他即将被带入一个新的政治场 | pressure: 基因反噬随时可能恶化

**Conflict:** 刚苏醒的林野身体虚弱、记忆断裂，既要对抗虫族威胁，又要承受首次基因适配的剧烈反噬反应

**Pacing:** fast

#### 外来者

**Summary:** 青藤据点勘探队将昏迷的林野和火种核心带回据点，老周连夜组装基础机甲；据点基因检测仪警报林野携带虫族基因波动引发驱逐争议，老周用仅剩的基因抑制剂缓解其反噬，众人发现其基因适配度远超普通进化者

**Characters:** 林野, 苏晴, 老周, 吴伯, 据点守门长老吴伯, 林野（昏迷）

**Location:** 青藤据点地下主厅及医疗区

**Events:**
- **苏晴** → discover → 林野 (character) @ 荒骨台废弃机甲测试场 | 勘探队将昏迷的林野与火种核心运回青藤据点，林野第一次进入人类据点环境
- **基因检测仪** → detect → 林野 (character) @ 青藤据点入口 | 林野携带虫族基因波动的身份引起据点守卫警惕，被要求接受进一步检查
- **老周** → identify → 旧时代军工铭牌 (item) @ 青藤据点医疗区 | 老周确认林野与旧时代火种项目有关，开始着手组装机甲零件
- **老周** → use → 基因抑制剂 (item) @ 青藤据点医疗区 | 林野基因稳定性回升至65%，暂时脱离反噬风险，苏醒过来
- **老周** → analyze → 林野 (character) @ 青藤据点医疗区 | 老周确认林野基因适配度高达77%，远超普通进化者，证实其与火种项目的特殊关联

**Beats:**
1. 随后，从荒骨台废弃机甲测试场前往青藤据点地下主厅及医疗区后，货车穿过地下岩洞入口进入据点，林野被抬下时据点石制拱顶下悬挂的旧式柴油灯散发昏黄光亮，大铁门内侧戍卫持有旧式弹簧弩，警惕地盯着陌生的入侵者
2. 入口检测仪发出蜂鸣报警，吴伯下令将林野移入隔离观察区，不允许任何人靠近
3. 老周翻查林野随身物品时发现军工铭牌——正面刻有2236年青藤军工厂字样，背面是旧人类军工系统的鹰徽与一串字母编号，老周年轻时见过类似铭牌，认出这是旧时代军工体系内的重要人物佩章
4. 他决定冒险私人拿出私藏的最后半支基因抑制剂，用小号注射器缓慢推入林野的手臂静脉
5. 吴伯皱眉看着基因扫描仪上林野77%的适配度数据，这与据点内普通基因进化者7%的数值形成强烈对比，沉默片刻后说：先留着观察三天，不能让他随便走动，也不能让他接触火种核心
6. 老周暗中提醒苏晴：这个外来者很可能是旧时代的重要人物，值得留下保护

**Opening Beat:** 随后，从荒骨台废弃机甲测试场前往青藤据点地下主厅及医疗区后，货车穿过地下岩洞入口进入据点，林野被抬下时据点石制拱顶下悬挂的旧式柴油灯散发昏黄光亮，大铁门内侧戍卫持有旧式弹簧弩，警惕地盯着陌生的入侵者

**Closing Beat:** 老周暗中提醒苏晴：这个外来者很可能是旧时代的重要人物，值得留下保护

**State Change:** 林野被带回据点，身份引起争议，老周通过基因抑制剂稳定其状态，发现其超常的基因适配度

**Chapter Payoff:**
- **Desire:** 在陌生据点生存下来，避免被当作威胁驱逐
- **Pressure:** 基因检测仪报警引发驱逐争议，可能被处决或驱逐出据点
- **Clever Move:** 老周认出旧时代军工铭牌，用基因抑制剂证明林野的价值
- **Payoff Moment:** 基因适配度高达77%的扫描结果让据点众人震惊
- **Reward:** 获得老周的信任和基因抑制剂救治
- **Social Proof:** 老周在据点威望较高，他的担保让林野暂时安全
- **Hook:** 虫群即将来袭的预警，据点的防御压力正在逼近

**Storyline Advances:**
- **火种远征主线** (pressure): 林野被青藤据点收留，但面临安全审查 | consequence: 据点内部分人对他的基因波动保持警惕，林野需要更多行动来建立信任 | pressure: 三天观察期内一旦被发现威胁据点安全，林野可能会被驱逐
- **青藤据点** (hook): 林野携带基因波动进入据点引发内部争论 | consequence: 据点内部裂痕初现，老周与吴伯对林野的态度分化 | pressure: 吴伯要求三天观察期，林野必须在时间窗口内证明价值

**Conflict:** 携带虫族波动的外来者引发驱逐争议，老周极力争取收留机会

**Pacing:** normal

#### 钢铁庇护

**Summary:** 老周花了一夜将基础外骨骼零件与火种核心组装成一套可穿戴的基础火种甲形态机甲；次日小规模虫群突袭据点防御墙，林野穿上机甲在防御墙有利地形和观测员指引下迎战虫群，首次向据点众人展示了火种机甲的战力，成功击退虫族，获得初步信任

**Characters:** 林野, 老周, 苏晴, 观测员老刘, 据点防守人员, 苏晴（瞭望台上提供指引）

**Location:** 青藤据点军械维修舱/地下岩洞防御墙前

**Events:**
- **老周** → upgrade → 基础火种甲形态 (item) @ 青藤据点军械维修舱 | 林野获得了第一套完整机甲形态，具备正面迎战虫群的战斗能力；热能短剑作为备用武器被整合进机甲左臂接口，弥补了机甲未配备远程武器的短板，让林野在战斗中多一层近战保障，也让他意识到老周的技术功底远超普通维修工——这位老人在百年废土中保留了旧人类军工的工艺火种
- **观测员老刘** → warn → 虫群接近据点防御墙 (state) @ 据点瞭望台 | 林野提前获知虫群来袭，有时间装备机甲并部署战术；他迅速与观测员老刘约定信号手势，将防御墙作为主战场，利用高处地形弥补战斗经验不足
- **林野** → combat → 虫群 (status) @ 青藤据点防御墙前 | 林野以防御墙地形分割虫群阵型、观测指引和尸体障碍战术弥补了机甲经验与数量劣势，成功击退虫群保住据点。基因稳定性从65%降至59%逼近反噬阈值，但战斗让林野首次完成了火种机甲的高强度神经同步实操，初步掌握了神经同步节奏——他发现自己越专注于战斗节奏，机甲的响应速度就越流畅，这为后续解锁武装集成甲积累了关键的操作数据和战术信心
- **火种核心** → calibrate → 火种核心校准数据 (state) @ 战斗结束后 | 获得首次实战校准数据——火种核心记录了机甲在虫群围攻下的能量分配效率与装甲承受极限，为下一形态（武装集成甲）解锁创造了前置条件；林野意识到火种机甲在实战中会自主优化能量输出曲线，这意味着战斗越多，机甲会越贴合他的战斗风格
- **吴伯** → befriend → 林野与据点的信任关系 (relationship) @ 青藤据点 | 林野从可疑外来者变为据点核心战力，获得独立居住空间和行动自由；吴伯私下对苏晴说了一句——「他身上那股拼劲，有点像我们那个时代的人」——这简短的认可意味着林野在据点高层眼中已从潜在威胁变成可用力量

**Beats:**
1. 随后，从青藤据点地下主厅及医疗区前往青藤据点军械维修舱/地下岩洞防御墙前后，老周用炭笔在旧金属板上绘制组装图，对照百年前在军工系统工作时学到的机械原理逐步骤组装火种核心与散件，反复调整齿轮咬合度，将3枚低级虫族晶核嵌入能量槽作为核心动力
2. 组装完成后，他测试手动操控杆的灵敏度，确认推杆可控制前行与转向、拉绳可控制手臂挥舞——一套纯机械的基础作战系统
3. 虫群从地面洞穴涌出，林野初上机甲重心不稳差点摔倒，旧机械控杆手感极沉，第一只工虫扑来时他只来得及横移肩膀用机甲肩甲硬磕
4. 连续找到操作节奏后砍翻四只工虫，兵虫螯肢插进机甲左臂护甲缝隙，林野咬牙反手用右臂热能短剑（核心余能驱动）削断兵虫前肢，虫群溃退
5. 苏晴从瞭望台看着机甲斩杀虫群的过程，低声向老周报告：这台东西至少能顶一个小队的旧式防御武器
6. 她想起老周说的『林野可能是旧时代关键人物』，决定暂时提供一些据点的基本情报作为回报

**Opening Beat:** 随后，从青藤据点地下主厅及医疗区前往青藤据点军械维修舱/地下岩洞防御墙前后，老周用炭笔在旧金属板上绘制组装图，对照百年前在军工系统工作时学到的机械原理逐步骤组装火种核心与散件，反复调整齿轮咬合度，将3枚低级虫族晶核嵌入能量槽作为核心动力

**Closing Beat:** 她想起老周说的『林野可能是旧时代关键人物』，决定暂时提供一些据点的基本情报作为回报

**State Change:** 林野通过组装基础火种甲并击退虫群，赢得据点初步信任，为后续行动奠定基础

**Chapter Payoff:**
- **Desire:** 用实战证明自己的价值，获得据点信任
- **Pressure:** 虫群（10工虫+1兵虫）即将突破防御墙，据点守备不足；基因稳定性仅65%，高强度战斗有反噬风险；这是他首次穿上完整机甲迎敌，对操作仅停留在理论层面
- **Clever Move:** 穿戴上刚组装完成的基础火种甲迎战，利用防御墙狭窄地形将虫群分割成两批逐批击破，以击杀工虫尸体制造障碍迟滞兵虫推进，配合观测员老刘的信号指引精准打击，同时将热能短剑整合进机甲左臂作为备用武器弥补远程短板
- **Payoff Moment:** 基础火种甲在防御墙高处碾压工虫、借地形障碍砍断兵虫前肢迫使退走的战术性战斗画面
- **Reward:** 获得据点居民的信任和吴伯的认可，分配独立房间；首次实战校准数据为后续升级奠基；初步掌握神经同步节奏，建立了战术信心
- **Social Proof:** 从可疑外来者变成据点核心战力担当，吴伯私下评价他『有点像我们那个时代的人』
- **Hook:** 沈氏情报网可能已监测到青藤据点的异常能量信号；基因稳定性降至59%逼近反噬阈值，下一次高强度战斗将面临更大风险
