# Story Outline

## 第一部分：火种再燃

**Summary:** 林野从百年沉睡中苏醒，在荒骨台激活火种机甲，被青藤据点收留。他逐步掌握基因进化力量，联合异变者与各方势力，揭开了百年前虫族入侵与自身遇袭的惊天阴谋，从个人复仇的初衷转变为领导人类反抗的信念，为最终的母巢反击与星际远征奠定基础。

### 第一卷：荒骨苏醒

**Summary:** 林野在荒骨台苏醒并激活火种机甲，被青藤据点收留后初步获得信任。他逐步掌握基因进化，击退虫族袭击，结识苏晴、老周、阿蝉等关键盟友。沈氏集团势力浮出水面，林野发现自身暗害真相与沈氏有关，在整合青藤据点、黄土沟据点及异变者势力的过程中遭遇沈氏暗算与虫族高级统领伏击，从旧文明数据芯片中获得关键线索，首次面临重大危机。

#### 荒骨苏醒

**Summary:** 林野被勘探队送入青藤据点医务室，老周花了一夜将带回的零件组装出基础火种机甲。林野因基因波动被检测仪器报警引发众怒，老周用仅剩的半支抑制剂缓解其反噬，苏晴替他担保争取时间。次日虫群突袭据点，老周紧急启动机甲让林野出战，他驾驶基础机甲孤身击退近十只工虫，据点民众初次见证火种机甲的威力，林野初步站稳脚跟。

**Characters:** 林野, 苏晴, 老周, 据点战士

**Location:** 青藤据点

**Events:**
- **老周** → assemble → 基础火种机甲 (item) @ 据点工坊，彻夜工作 | 老周将林野带回的零件组装成完整机甲
- **林野** → discover → 基因波动报警 (status) @ 据点医务室检测仪器 | 林野因携带虫族基因波动的残留被仪器报警，引发怀疑
- **老周** → use → 基因抑制剂 (item) @ 医务室 | 老周用仅剩的半支抑制剂缓解林野的基因反噬症状
- **林野** → combat @ 据点外墙防线 | 林野驾驶组装完毕的基础机甲击退十只工虫，展现火种机甲战力

**Beats:**
1. 林野在冰冷的地板上苏醒，身上盖着破旧的毯子，周围是陌生的据点环境和警惕的民众；老周正在工坊里彻夜组装基础火种机甲，零件碰撞的声音隐约传来
2. 基因检测仪突然发出刺耳警报，据点民众情绪激动地质问林野的身份，苏晴站出来喝止骚动，老周用仅剩的半支抑制剂注射进林野体内，反噬症状暂时缓解
3. 虫群从据点外缘涌来，近十只工虫撞向外墙，防御武器开火但难以阻止突破；老周紧急启动刚组装好的机甲，将林野推进驾驶舱，林野用残存体力驾驶基础机甲冲出外墙防线
4. 林野在虫群中连续斩杀工虫，机甲基础近战模块撕裂一只又一只工虫外壳，据点民众在墙头目睹这一幕，从最初的恐惧逐渐转变为震撼与希望；最后一只工虫倒地后，据点战士发出欢呼

**Opening Beat:** 林野在冰冷的地板上苏醒，身上盖着破旧的毯子，周围是陌生的据点环境和警惕的民众；老周正在工坊里彻夜组装基础火种机甲，零件碰撞的声音隐约传来

**Closing Beat:** 林野在虫群中连续斩杀工虫，机甲基础近战模块撕裂一只又一只工虫外壳，据点民众在墙头目睹这一幕，从最初的恐惧逐渐转变为震撼与希望；最后一只工虫倒地后，据点战士发出欢呼

**State Change:** 林野在据点站稳脚跟，获得初步信任与盟友。

**Storyline Advances:**
- **第二章：青藤据点** (payoff): 林野获得据点初步信任，成为据点战力核心 | consequence: 与老周、苏晴建立初步盟友关系 | pressure: 击退虫群后，据点面临更大规模虫群报复的风险

**Conflict:** 林野必须消除据点民众的疑虑并证明自己的价值，同时抵御突袭的虫群。

**Pacing:** normal

#### 初探遗址

**Summary:** 林野伤愈后吸收低级虫族晶核稳定基因至1级，与苏晴、老周前往附近旧文明遗址探索，获得一枚旧文明数据芯片，发现沈氏与火种机甲项目相关的模糊线索。

**Characters:** 林野, 苏晴, 老周

**Location:** 青藤据点及附近旧工厂遗址

**Events:**
- **林野** → use → 低级虫族晶核 (item) @ 据点训练室 | 林野吸收一枚低级晶核，基因稳定性提升至75%，彻底稳定在1级
- **林野** → recover → 伤势 (status) @ 据点医务室休养三天 | 林野在据点的简单医疗和自身恢复力下，基因反噬症状完全消退
- **林野** → meet → 苏晴 (character) @ 据点走廊 | 苏晴主动向他介绍据点历史与当前人类生存状况
- **林野** → discover → 旧文明数据芯片 (item) @ 旧工厂废墟控制室 | 林野在工厂废墟中发现一枚完好的旧文明数据芯片
- **林野** → combat @ 工厂废墟车间 | 击杀三只游荡工虫，清理探索区域

**Beats:**
1. 林野吸收低级晶核，基因稳定性上升到75%，身体机能大幅提升
2. 苏晴介绍百年来人类据点的分布与沈氏势力的基本情报
3. 进入工厂废墟，清理游荡工虫
4. 控制室中发现一枚完好的旧文明数据芯片

**Opening Beat:** 林野吸收低级晶核，基因稳定性上升到75%，身体机能大幅提升

**Closing Beat:** 控制室中发现一枚完好的旧文明数据芯片

**State Change:** 林野稳定基因至1级，获得第一枚数据芯片，发现沈氏线索。

**Storyline Advances:**
- **历史真相支线** (reveal): 获得关于沈氏与火种机甲项目关联的第一个模糊证据 | pressure: 芯片信息让林野意识到沈氏可能在百年前就参与了火种机甲项目，暗害自己的迷雾更浓

**Conflict:** 林野需要提升自身实力并收集旧文明信息，同时防范废土上的虫族威胁。

**Pacing:** normal

#### 虫群压境

**Summary:** 更大规模的虫群（20工虫+1兵虫）进攻青藤据点，林野与苏晴合力防守，虽击退虫群但据点损失惨重，林野从兵虫体内获得重要晶核。

**Characters:** 林野, 苏晴, 老周, 据点民众, 据点战士

**Location:** 青藤据点外墙

**Events:**
- **林野** → discover → 虫群异常集结 (status) @ 据点瞭望塔 | 侦察兵报告约20只工虫和1只作战兵虫正向据点移动
- **林野** → combat @ 据点外墙防线 | 林野驾驶机甲与苏晴配合，击杀全部工虫和兵虫，但据点损失5名战士
- **林野** → acquire → 低级虫族晶核 (item) @ 兵虫尸体 | 从作战兵虫体内挖出一枚低级晶核，另从工虫群中获得2枚
- **老周** → use → 修理材料 (item) @ 据点工坊 | 老周战后修复了机甲部分损坏的装甲

**Beats:**
1. 虫群涌来，林野驾驶机甲冲出与工虫混战
2. 苏晴用旧式狙击枪掩护，击杀多名工虫
3. 兵虫破坏大门，林野用机甲冲撞将其击退
4. 找到兵虫腹部弱点一击毙命
5. 清点损失：5名战士牺牲
6. 老周从兵虫体内取出低级晶核交给林野

**Opening Beat:** 虫群涌来，林野驾驶机甲冲出与工虫混战

**Closing Beat:** 老周从兵虫体内取出低级晶核交给林野

**State Change:** 林野成功防守据点，获得更多晶核，但意识到虫族威胁升级。

**Storyline Advances:**
- **火种远征主线** (pressure): 据点面临有组织的虫族攻击，林野意识到需要快速提升实力 | pressure: 有兵虫指挥的攻击模式暗示虫族正在调整战术，后续威胁只会更严峻

**Conflict:** 据点必须顶住这次集中进攻，否则将失去生存空间。

**Pacing:** fast

#### 黄土沟的邀请

**Summary:** 黄土沟据点派使者提议结盟，林野与苏晴代表青藤准备前往谈判，出发前在据点大门外遭沈氏雇佣的赏金猎人伏击，林野击退伏击并活捉一人审问，从俘虏身上搜出标注有虫族活动区域的旧地图，拼凑出沈氏与虫族有情报往来的线索。随后启程抵达黄土沟，初步达成合作意向。

**Characters:** 林野, 苏晴, 黄土沟使者, 沈氏赏金猎人, 黄土沟首领, 赏金猎人（俘虏）, 赏金猎人

**Location:** 青藤据点及前往黄土沟的地表路段

**Events:**
- **黄土沟使者** → propose → 联盟 (relationship) @ 青藤据点会议室 | 黄土沟使者提出共同对抗虫族的结盟意向
- **沈氏赏金猎人** → combat @ 青藤据点大门外一百米处 | 林野与苏晴刚离开据点即遭4名赏金猎人伏击，林野驾驶机甲击退敌人，活捉一人审问
- **林野** → discover → 沈氏与虫族勾结证据 (knowledge) @ 据点临时审讯室 | 从俘虏身上搜出标注有虫族活动区域的旧地图，发现沈氏与虫族有情报往来
- **林野** → meet → 黄土沟首领 (character) @ 黄土沟据点大厅 | 抵达黄土沟，与首领初步商讨结盟细节，双方同意建立共同防御

**Beats:**
1. 黄土沟使者在据点会议室提出结盟，林野决定立刻出发；刚走出据点大门一百米，四名赏金猎人从废墟中突袭
2. 林野驾驶机甲与苏晴配合，击杀三人活捉一人
3. 赏金猎人交代是沈氏雇佣，专盯基因适配者
4. 从俘虏身上搜出标注有虫族活动区域的旧地图，林野将地图碎片与据点周边虫群分布对比，推断沈氏可能出卖人类行踪——他意识到这片区域的游荡虫群数量异常，与沈氏标注的路线高度吻合
5. 林野与苏晴重新上路，途中无更多意外
6. 黄土沟首领热情接待；双方初步商议建立联盟和共同防御计划

**Opening Beat:** 黄土沟使者在据点会议室提出结盟，林野决定立刻出发；刚走出据点大门一百米，四名赏金猎人从废墟中突袭

**Closing Beat:** 黄土沟首领热情接待；双方初步商议建立联盟和共同防御计划

**State Change:** 林野通过伏击获得沈氏与虫族勾结的间接证据，并与黄土沟结盟。

**Storyline Advances:**
- **势力整合支线** (pressure): 林野首次与沈氏势力正面冲突，发现沈氏可能勾结虫族 | consequence: 黄土沟联盟初步建立，同时暴露了林野的行踪；林野通过地图推理确认沈氏故意将虫群引向人类据点

**Conflict:** 林野必须在离开据点前就应对沈氏的暗杀，同时确保安全抵达黄土沟完成联盟谈判。

**Pacing:** fast

#### 异变者之影

**Opening Beat:** 首领介绍异变者情况，警告接触风险

**Closing Beat:** 林野承诺优先营救，阿蝉同意提供情报和异变者战力

**State Change:** 林野与异变者结盟，确定营救适配者的目标。

**Pacing:** slow

#### 沈氏的暗算

**Summary:** 林野返回青藤据点途中遭沈氏勾结虫族高级统领设伏，大量兵虫和初级虫将围攻，林野苦战后濒死突破至2级基因，解锁近战模块击退虫族，并从先前获取的情报中拼凑出沈氏与虫族勾结的确凿证据链。

**Characters:** 林野, 苏晴, 阿蝉, 虫族高级统领

**Location:** 青藤据点与黄土沟之间的地表废墟走廊

**Events:**
- **林野** → discover → 虫群陷阱 (status) @ 返回途中废弃建筑群 | 林野发现大量虫族已有预谋地包围了他们，高级统领在远处指挥
- **虫族高级统领** → combat @ 废墟走廊伏击 | 林野小队被围攻，苏晴和阿蝉的异变者受伤，林野机甲严重损坏
- **林野** → transform → 基因等级2级 (skill) @ 生死关头，临时吸收战场上兵虫的晶核 | 林野基因稳定性跌至临界点，但强行突破至2级，解锁近战武器模块
- **林野** → combat @ 废墟中心 | 林野用新解锁的近战武器斩杀虫将，高级统领见势撤退，虫群溃散

**Beats:**
1. 发现周围虫群异常聚集，数量远超以往
2. 高级统领从远处发出精神力波动，指挥虫群合围；林野注意到虫群出现的路径正是赏金猎人地图上沈氏标注的路线，脑中闪过一个念头——这不是巧合，沈氏出卖了他们的行踪
3. 林野机甲被虫将击穿，左臂受伤
4. 苏晴和阿蝉掩护，林野临时吸收兵虫晶核强行进化；基因波动濒临崩溃，但成功突破至2级
5. 解锁近战武器模块，斩杀虫将
6. 高级统领撤退，虫群失去指挥溃散；林野因基因刚突破体力透支，被苏晴搀扶离开

**Opening Beat:** 发现周围虫群异常聚集，数量远超以往

**Closing Beat:** 高级统领撤退，虫群失去指挥溃散；林野因基因刚突破体力透支，被苏晴搀扶离开

**State Change:** 林野突破至2级基因并获得沈氏勾结证据，但自身代价惨重。

**Storyline Advances:**
- **火种远征主线** (reversal): 林野首次面临生死危机后突破至2级，发现沈氏与虫族勾结的确凿证据 | consequence: 林野实力提升，但也使沈氏和虫族高级统领明确将他视为必须清除的目标

**Conflict:** 林野必须从沈氏与虫族联合设下的死局中存活并保护同伴。

**Pacing:** fast

- **林野** → recover → 伤势 (status) @ 据点医务室 | 林野利用基因2级的自愈能力在五天内伤势痊愈，基因稳定性达到75%
- **老周** → use → 数据芯片读卡器 (item) @ 据点工坊 | 老周尝试破解初级芯片，发现其中指向一个旧军事基地的位置

- **林野** → capture → 沈氏卧底 (character) @ 基地出口 | 潜伏在青藤据点后勤处的卧底试图偷走芯片，被林野擒获，供出沈氏近百年来一直在监控火种机甲适配者信息
