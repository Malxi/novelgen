# Story Outline

## 第一部：废土苏醒

**Summary:** 本部分为故事开篇核心弧，讲述21世纪基因研究员林越参与时空实验进入低温休眠舱后，意外穿越到三千年后被虫族入侵、人类文明破碎的废土地球，在变异生物横行、流浪AI流窜、人类部落割据的末世环境中觉醒基因进化天赋，获得旧世界联邦遗留的初代机甲，集结第一批伙伴，成功避开即将孵化的虫族母巢危机，踏出逐星远征、重建人类统一文明的第一步。

### 第一卷：地球残响

**Summary:** 本卷聚焦林越苏醒后的初期求生与立足，全程围绕废土地球的生存挑战展开：包含苏醒后遭遇虫族幼体、结识废土拾荒小队、破解旧世界AI数据库、绑定初代单兵机甲、解决黄土部落水源危机、合并邻近部落、揭露人类联邦覆灭的真相、发现虫族母巢孵化危机，最终集结30人规模的首批队伍，乘坐修复完成的近地穿梭舰升空前往近轨道空间站，为后续跨星远征完成全部铺垫。

#### 休眠舱的嗡鸣

**Summary:** 21世纪基因研究员林越参与跨时空实验进入低温休眠舱，意外在三千年后的废弃地下科研基地中苏醒，发现所处世界已经面目全非。

**Characters:** 林越

**Location:** 旧世界地下科研基地低温舱区

**Events:**
- **林越** → discover → 未来废土世界 (location) @ 地下低温休眠设施 | 林越确认自己穿越到了5023年的末世地球

**Beats:**
1. 林越在低温舱的唤醒提示音中睁开眼
2. 查看休眠舱系统报错信息，发现当前年份为5023年
3. 砸开故障的休眠舱门走出舱体
4. 发现科研基地遍地废弃残骸与干涸的不明生物血迹

**Opening Beat:** 故事开篇，林越在低温舱的电子提示音中逐渐恢复意识

**Closing Beat:** 林越刚走到基地走廊转角，就听见拐角后传来黏腻的爬行声响

**State Change:** 林越确认自己穿越到三千年后的末世

**Conflict:** 林越身无寸铁，对当前环境完全陌生，未知威胁正在靠近

**Pacing:** 中等偏快

#### 第一只虫族幼体

**Summary:** 林越遭遇虫族最低级的幼体猎食者，在绝境中意外觉醒基因进化天赋，成功反杀虫族幼体。

**Characters:** 林越

**Location:** 旧世界科研基地走廊

**Events:**
- **林越** → combat → 虫族幼体 (character) @ 废弃科研基地走廊 | 林越击杀虫族幼体，获得第一块虫族基因碎片

**Beats:**
1. 长满骨刺的黑色虫族幼体从拐角扑出袭击林越
2. 林越慌乱中躲到废弃金属柜后避过攻击
3. 濒死关头身体发热觉醒基因力量
4. 用身边的钢管刺穿虫族幼体头颅

**Opening Beat:** 承接上章，林越看见虫族幼体从拐角爬出来，瞬间僵在原地

**Closing Beat:** 林越刚缓过气，就听见走廊尽头传来人类的脚步声与喊话声

**State Change:** 林越觉醒基因进化能力，首次击杀虫族

**Conflict:** 毫无战斗经验的林越对上攻击性极强的虫族幼体，生存概率极低

**Pacing:** 快

#### 流浪的拾荒小队

**Summary:** 林越遇到以苏晓为首的三人拾荒小队，双方短暂对峙后达成合作，一同前往小队的临时营地。

**Characters:** 林越, 苏晓, 大虎, 阿明

**Location:** 旧世界科研基地入口

**Events:**
- **苏晓** → meet → 林越 (character) @ 科研基地出入口 | 林越加入拾荒小队，获得基础生存物资

**Beats:**
1. 拾荒小队举着武器对准林越
2. 苏晓确认林越不是敌对势力成员
3. 林越拿出虫族幼体的核心证明自己的战斗力
4. 小队同意带林越返回黄土部落营地

**Opening Beat:** 承接上章，苏晓带着大虎和阿明从走廊尽头出现，举枪对准林越

**Closing Beat:** 一行人走到基地外，林越第一次看见被黄沙覆盖、巨型虫族残骸散落的废土地表全貌

**State Change:** 林越结识第一批废土伙伴，获得生存补给

**Conflict:** 拾荒小队对陌生的林越充满警惕，双方差一点爆发武力冲突

**Pacing:** 中等

#### 部落的生存困境

**Summary:** 林越跟随小队回到黄土部落，发现部落因为水源被虫族污染，正面临全族覆灭的危机。

**Characters:** 林越, 苏晓, 黄土族长, 部落民众

**Location:** 黄土部落临时聚居点

**Events:**
- **黄土族长** → announce → 水源危机通知 (status) @ 黄土部落议事棚 | 全部落进入紧急生存状态

**Beats:**
1. 林越跟随小队进入黄土部落范围
2. 发现部落民众大多因为喝了污染的水上吐下泻
3. 族长说明虫族最近占领了上游唯一的净水点
4. 部落剩余淡水只够支撑三天

**Opening Beat:** 承接上章，林越跟着小队穿过黄沙屏障，进入黄土部落的聚居范围

**Closing Beat:** 林越主动提出自己可以前往被虫族占领的净水点，清理污染、夺回水源

**State Change:** 林越得知黄土部落的生存危机，决定出手解决

**Conflict:** 黄土部落的水源被虫族占领，剩余物资不足以支撑全族迁徙到其他水源地

**Pacing:** 中等

#### 遗留的AI数据库

**Summary:** 林越返回之前的科研基地，破解了基地遗留的联邦AI核心数据库，获得旧世界净水技术资料与初代机甲核心的存放坐标。

**Characters:** 林越, 星核AI

**Location:** 旧世界科研基地核心机房

**Events:**
- **林越** → discover → 联邦AI数据库 (knowledge) @ 科研基地核心机房 | 林越破解数据库权限，绑定AI「星核」为自己的辅助系统

**Beats:**
1. 林越独自返回科研基地
2. 找到核心机房的加密大门
3. 用自己21世纪研究员的权限密码成功解锁系统
4. 激活沉睡的基地AI「星核」，获得大量旧世界技术资料

**Opening Beat:** 承接上章，林越告别苏晓，独自出发返回废弃科研基地寻找解决方案

**Closing Beat:** 星核告知林越，基地地下机库存放着一台完好的初代单兵作战机甲，可用来对抗虫族

**State Change:** 林越激活旧世界AI，获得机甲与技术资料

**Conflict:** 数据库加密等级极高，林越只有三次尝试解锁的机会，失败就会触发自毁程序

**Pacing:** 中等偏慢

#### 初代机甲「银翼」

**Summary:** 林越在地下机库找到初代机甲银翼，成功完成基因绑定，获得足以对抗成年虫族的战斗力。

**Characters:** 林越, 星核AI

**Location:** 旧世界科研基地地下机库

**Events:**
- **林越** → acquire → 银翼机甲 (item) @ 地下机库 | 林越战斗力大幅提升，拥有了正面对抗虫族的能力

**Beats:**
1. 林越跟着星核的指引进入地下机库
2. 看见覆盖着防尘布的银翼机甲
3. 进行基因绑定验证，适配度达到98%
4. 首次启动机甲，测试各项功能全部正常

**Opening Beat:** 承接上章，林越跟着星核的导航，打开了地下机库的厚重合金门

**Closing Beat:** 林越驾驶机甲飞出基地，直奔上游的虫族占领净水点

**State Change:** 林越获得初代机甲，战斗力达到废土顶尖水平

**Conflict:** 机甲绑定要求驾驶员基因等级达到F级以上，若适配度过低会触发机甲自毁

**Pacing:** 快

#### 净水点争夺战

**Summary:** 林越驾驶银翼机甲抵达净水点，全歼占据净水点的12只成年虫族，成功清理水源污染，将净水带回黄土部落。

**Characters:** 林越, 星核AI

**Location:** 上游河谷净水点

**Events:**
- **林越** → combat → 成年虫族小队 (character) @ 上游河谷净水点 | 林越全歼虫族，夺回净水点控制权

**Beats:**
1. 林越驾驶机甲抵达净水点
2. 虫族群起攻击，被机甲的粒子炮逐一击杀
3. 启动净水系统的过滤程序，清理水源中的虫族毒素
4. 装满十桶淡水准备返回部落

**Opening Beat:** 承接上章，林越驾驶机甲低空飞过黄沙地表，很快抵达上游河谷的净水点范围

**Closing Beat:** 林越带着淡水回到部落，却发现部落外围有另一支人类部落的人马正在围攻

**State Change:** 林越夺回净水点，彻底解决黄土部落的水源危机

**Conflict:** 占据净水点的虫族数量远超预期，林越初次驾驶机甲还不熟练，稍有不慎就会损坏机甲核心

**Pacing:** 快

#### 部落间的同盟

**Summary:** 林越击退入侵的黑岩部落，与黑岩部落族长达成和平协议，两个部落合并，为后续远征积累了第一批人力。

**Characters:** 林越, 苏晓, 黑岩族长, 黄土族长

**Location:** 黄土部落外围

**Events:**
- **林越** → establish → 部落同盟 (relationship) @ 黄土部落营地外围 | 合并后的部落总人数达到30人，拥有充足的物资与战斗力

**Beats:**
1. 林越看见黑岩部落的人正在攻打黄土部落
2. 驾驶机甲落在战场中间，威慑黑岩部落的人马
3. 黑岩族长认出银翼是旧世界联邦的机甲，主动提出和谈
4. 双方达成协议，黑岩部落并入黄土部落，由林越担任最高指挥

**Opening Beat:** 承接上章，林越带着淡水返回部落，远远就看见部落方向冒着浓烟，传来喊杀声

**Closing Beat:** 星核突然发来警报，检测到地下3000米处有虫族母巢的能量反应，一周后就会孵化爆发

**State Change:** 两个部落合并，林越拥有了第一批属于自己的队伍

**Conflict:** 黑岩部落为了抢夺水源来犯，双方实力差距不大，硬拼只会两败俱伤让虫族得利

**Pacing:** 中等

#### 人类覆灭的真相

**Summary:** 林越通过星核调取的卫星数据，得知三千年虫族入侵、人类联邦覆灭的全部真相，同时发现近地轨道上还有一座完好的联邦空间站可以作为远征跳板。

**Characters:** 林越, 苏晓, 星核AI, 部落核心成员

**Location:** 黄土部落议事棚

**Events:**
- **星核AI** → transform → 世界观信息 (knowledge) @ 部落议事棚 | 所有人得知末世真相，统一了前往宇宙寻找幸存人类的目标

**Beats:**
1. 林越召集所有核心成员开会
2. 星核投影出三千年虫族入侵的历史记录：虫族从外太空降临，吃掉了90%的人类，联邦残余部队逃往其他星系
3. 星核检测到近地轨道有一座完好的联邦空间站，里面有星际穿梭舰可以使用
4. 所有人一致同意跟随林越离开地球，前往宇宙寻找其他幸存人类

**Opening Beat:** 承接上章，林越在议事棚内放出星核检测到的虫族母巢能量波动数据，告知所有人留在地球只有死路一条

**Closing Beat:** 众人决定三天后出发，前往旧世界航天发射基地修复近地穿梭舰

**State Change:** 所有人知晓末世真相，确定了离开地球远征的目标

**Conflict:** 虫族母巢即将孵化，留在地球必死无疑，但是前往宇宙的风险未知，很多民众产生了动摇

**Pacing:** 中等偏慢

#### 驶离地表的穿梭舰

**Summary:** 所有人收拾好物资前往航天发射基地，成功修复穿梭舰，在虫族母巢孵化的前一刻升空，前往近地轨道空间站，正式开启逐星远征的旅程。

**Characters:** 林越, 苏晓, 大虎, 阿明, 所有部落成员

**Location:** 旧世界航天发射基地

**Events:**
- **林越** → move → 近地轨道空间站 (location) @ 航天发射基地 | 穿梭舰成功升空，脱离地球重力，前往近地轨道

**Beats:**
1. 所有人带着物资抵达航天发射基地
2. 林越用星核的权限解锁发射台系统，修复穿梭舰的故障
3. 地面开始震动，虫族母巢提前孵化，大量虫族涌向发射基地
4. 穿梭舰在最后一刻点火升空，成功脱离地表

**Opening Beat:** 承接上章，三天后，所有人收拾好全部家当，准时出发前往航天发射基地

**Closing Beat:** 穿梭舰进入太空，林越看着窗外越来越小的蓝色星球，以及远处密密麻麻的虫族宇宙母舰残骸，知道真正的逐星旅程才刚刚开始

**State Change:** 远征队成功离开地球，逐星主线正式开启

**Conflict:** 虫族母巢提前孵化，大量虫族涌向发射基地，差一点就摧毁了还没点火的穿梭舰

**Pacing:** 极快
