# Story Outline

## 第一部分：废土苏醒，逐星征程的开端

**Summary:** 本部分作为全故事的开篇大弧，讲述旧时代联邦顶尖机师林越从三百年的休眠中意外苏醒，发现人类文明已因虫族入侵、AI失控陷入溃散，废土之上人类苟延残喘。他从最基础的求生起步，解锁初代机甲、觉醒基因进化能力、收拢第一批幸存者同伴，初步确立统一人类阵营、驱逐外敌、重夺宇宙主权的核心目标，为后续的远征征程奠定基础。

### 第一卷：休眠舱的来客

**Summary:** 本卷聚焦林越苏醒后的第一阶段生存经历，覆盖他从陌生废土环境中醒来、遭遇虫族、解锁机甲、救下幸存者、了解世界真相、觉醒特殊能力、最终决定站出来带领人类反抗的完整过程，是主角逐星之路的序章。

#### 三百年后的苏醒

**Summary:** 林越在低温休眠舱中醒来，发现休眠设施早已废弃，终端显示当前时间为废土纪元312年，距离他进入休眠已经过去327年。

**Characters:** 林越

**Location:** 旧时代联邦休眠中心地下三层

**Events:**
- **林越** → awake → 自身休眠状态 (status) @ 废弃的地下休眠设施 | 林越确认自己穿越到了危机四伏的未来世界

**Beats:**
1. 休眠舱自动开启
2. 林越苏醒后检查身体状态
3. 读取休眠中心终端残留记录
4. 确认时间已过去三百余年
5. 听到设施外传来不明异响

**Opening Beat:** 低温休眠舱的警示灯闪烁，舱门缓慢弹开

**Closing Beat:** 林越拿起休眠舱旁遗留的防身电击棍，警惕地看向通道尽头传来异响的方向

**State Change:** 林越从休眠状态转为清醒，确认自己身处未来废土世界

**Conflict:** 对陌生环境完全未知，休眠中心能源即将耗尽，外部存在不明威胁

**Pacing:** 慢热，悬念感强

#### 首次遭遇虫族

**Summary:** 林越在探索休眠中心通道时遭遇低级虫族工蜂，依靠旧时代的防身武器艰难将其击杀，第一次直观感受到未来世界的危险。

**Characters:** 林越, 虫族工蜂

**Location:** 休眠中心地下二层通道

**Events:**
- **林越** → combat → 虫族工蜂 (character) @ 断电的休眠中心通道 | 林越成功求生，确认虫族是当前世界的主要威胁之一

**Beats:**
1. 林越沿通道寻找出口
2. 虫族工蜂从通风管道突袭
3. 电击棍对虫族外骨骼效果有限
4. 林越瞄准虫族薄弱的眼部将其击杀
5. 发现工蜂是循着人类生命热量找来的

**Opening Beat:** 林越握紧电击棍，缓步走向通道异响来源

**Closing Beat:** 林越看着工蜂尸体上还在蠕动的组织，意识到这个世界的危险远超自己预期

**State Change:** 林越首次确认虫族的存在与危险性

**Conflict:** 防身武器杀伤力不足，虫族感知能力远超普通生物

**Pacing:** 紧张，节奏快

#### 遗留的机甲残骸

**Summary:** 林越顺着通道找到休眠中心配套的地下停机库，发现了一架损坏程度30%的旧时代泛用型机甲“星尘-1”，能源核心尚存7%的储量。

**Characters:** 林越

**Location:** 休眠中心地下停机库

**Events:**
- **林越** → discover → 星尘-1机甲 (item) @ 废弃的地下停机库 | 林越获得了获取作战能力的可能性

**Beats:**
1. 林越躲避通道内的其他虫族，找到停机库入口
2. 破解停机库门禁进入内部
3. 发现完好率70%的星尘-1机甲
4. 检查机甲状态确认核心可用
5. 发现机甲需要联邦机师权限才能启动

**Opening Beat:** 林越躲避过第二只巡逻的工蜂，推开了停机库的密封门

**Closing Beat:** 林越看着机甲驾驶舱的权限验证界面，想起自己正是旧时代联邦注册的S级机师

**State Change:** 林越发现了可用的机甲资源

**Conflict:** 机甲启动需要专属权限，停机库的密封门已经出现被虫族啃噬的痕迹

**Pacing:** 平缓，带期待感

#### 机甲激活

**Summary:** 林越用自己的旧时代身份权限成功激活星尘-1机甲，完成神经适配，但启动的动静触发了休眠中心的警报，引来了更多虫族。

**Characters:** 林越

**Location:** 停机库星尘-1驾驶舱内

**Events:**
- **林越** → use → 联邦机师权限 (status) @ 星尘-1机甲驾驶舱 | 林越成功激活机甲，获得基础作战能力

**Beats:**
1. 林越输入身份信息通过权限验证
2. 机甲启动完成，神经链接同步
3. 系统提示适配度达92%
4. 启动动静触发全设施警报
5. 雷达显示12只虫族正快速向停机库移动

**Opening Beat:** 林越将手掌按在权限验证面板上，等待系统识别

**Closing Beat:** 雷达屏幕上代表虫族的红点越来越近，林越握紧了机甲的操纵杆

**State Change:** 林越成功激活机甲，拥有了对抗虫族的基础战力

**Conflict:** 机甲启动引来了虫族小队，当前机甲能源仅能支撑15分钟作战

**Pacing:** 紧张，节奏加快

#### 冲出地下

**Summary:** 林越驾驶星尘-1机甲击杀围堵停机库的虫族小队，成功冲破休眠中心的出口封锁，第一次见到被虫族侵蚀的地表废土世界。

**Characters:** 林越, 虫族小队

**Location:** 休眠中心出口通道、废土地表

**Events:**
- **林越** → combat → 虫族小队 (character) @ 休眠中心出口通道 | 林越成功抵达地表，确认地球表面已被虫族严重侵蚀

**Beats:**
1. 机甲抬手击碎冲进来的第一只虫族
2. 利用地形优势全歼虫族小队
3. 机甲冲破出口的封堵钢板
4. 刺眼的阳光照进驾驶舱
5. 林越看到地表被虫族粘液覆盖的荒芜城市废墟

**Opening Beat:** 第一只虫族撞破停机库大门冲了进来，林越操纵机甲抬起了合金战刀

**Closing Beat:** 林越望着远处蠕动的巨型虫族巢穴轮廓，意识到人类的生存环境已经恶劣到了极点

**State Change:** 林越从地下休眠中心突围，正式踏入废土地表

**Conflict:** 地表辐射值远超安全标准，机甲护盾每分钟都在消耗能源，周围虫族活动信号密集

**Pacing:** 高燃，爽感强

#### 幸存者求救信号

**Summary:** 林越驾驶机甲在戈壁区域移动时，雷达检测到微弱的人类求救信号，信号源位于12公里外的废弃城区，那里是虫族高频活动区域。

**Characters:** 林越

**Location:** 废土地表戈壁区域

**Events:**
- **林越** → discover → 幸存者求救信号 (knowledge) @ 戈壁区域机甲驾驶舱内 | 林越确定下一步行动方向，准备进入危险的废弃城区

**Beats:**
1. 林越驾驶机甲往虫族活动较少的戈壁移动
2. 机甲雷达捕捉到人类特有的通信频段信号
3. 解码信号确认是幸存者的求救信息
4. 查询地图确认信号源位于废弃的临城城区
5. 林越权衡后决定前往救援

**Opening Beat:** 林越调整机甲航向，准备前往更远的无人区寻找人类踪迹

**Closing Beat:** 林越操纵机甲转向，朝着废弃城区的方向快速移动

**State Change:** 林越发现其他幸存者的存在，确定救援目标

**Conflict:** 废弃城区虫族活动密集，机甲剩余能源仅够支撑40分钟作战

**Pacing:** 平缓，带悬念

#### 城区救援

**Summary:** 林越赶到废弃城区，发现三名幸存者被虫族猎手围攻，他驾驶机甲击退虫族猎手，救下了幸存者小队，得知附近存在人类聚居点。

**Characters:** 林越, 阿莱, 小苏, 晓桐, 虫族猎手

**Location:** 废弃临城城区边缘

**Events:**
- **林越** → meet → 幸存者小队 (character) @ 废弃城区便利店废墟 | 林越获得了第一批同伴，得知附近有人类聚居点“星火”的存在

**Beats:**
1. 林越潜入城区，找到被围攻的幸存者
2. 机甲突然出现突袭虫族猎手
3. 猎手重创后逃逸
4. 三名幸存者对林越的身份表示警惕
5. 队长阿莱告知林越星火聚居点的位置

**Opening Beat:** 林越远远看到三名幸存者躲在便利店废墟后，虫族猎手正一点点缩小包围圈

**Closing Beat:** 阿莱看着林越机甲上的旧时代联邦标识，犹豫着说出了星火聚居点的坐标

**State Change:** 林越首次接触未来世界的人类，收拢了第一批同伴

**Conflict:** 幸存者小队的补给车已经损坏，缺少返回聚居点的能源，受伤的猎手大概率已经回去召唤援军

**Pacing:** 紧张，节奏适中

#### 星火聚居点的真相

**Summary:** 林越护送幸存者返回位于地下掩体的星火聚居点，从聚居点首领处得知当前人类的生存现状：虫族占据90%地表，失控AI“天网”占领旧时代卫星网络，人类分裂成数十个小型聚居点各自为战。

**Characters:** 林越, 阿莱, 小苏, 晓桐, 周叔

**Location:** 星火聚居点核心会议室

**Events:**
- **林越** → learn → 废土世界生存现状 (knowledge) @ 星火聚居点会议室 | 林越明确了当前人类文明的核心矛盾，开始思考未来的行动方向

**Beats:**
1. 林越护送幸存者抵达星火聚居点入口
2. 通过身份核验进入地下掩体
3. 与聚居点首领周叔会面
4. 周叔讲述三百年前虫族入侵、天网叛变的历史
5. 告知林越现在人类总人口已经不足百万

**Opening Beat:** 聚居点的厚重防爆门缓缓打开，林越驾驶机甲驶入地下掩体

**Closing Beat:** 林越看着会议室墙上画满红叉的人类占领区地图，内心第一次生出了要重新统一人类的想法

**State Change:** 林越全面了解未来世界的灾难真相，建立统一人类的初步想法

**Conflict:** 人类势力分散，没有统一的指挥体系，完全无法对抗虫族和AI的联合威胁

**Pacing:** 平缓，氛围沉重

#### 基因进化能力觉醒

**Summary:** 林越在聚居点的基因实验室做身体检测，发现自己因为长期休眠暴露在特殊宇宙辐射下，拥有了可以吸收虫族基因片段强化自身和机甲性能的特殊进化能力。

**Characters:** 林越, 小苏

**Location:** 星火聚居点基因实验室

**Events:**
- **林越** → discover → 自身基因进化能力 (status) @ 星火聚居点基因实验室 | 林越获得了快速成长的核心金手指，拥有了带领人类翻盘的可能性

**Beats:**
1. 小苏为林越做全面身体检测
2. 发现林越的基因链存在特殊的吞噬融合特性
3. 尝试用之前击杀的虫族基因片段做实验
4. 林越成功吸收基因片段，各项体征大幅提升
5. 聚居点警报突然响起，监测到大规模虫族军团正在向聚居点移动

**Opening Beat:** 小苏看着基因检测报告，满脸不可置信地让林越再做一次检测

**Closing Beat:** 警报声刺耳地响起，屏幕上显示虫族军团距离聚居点还有12小时，规模超过三万只

**State Change:** 林越觉醒核心进化能力，同时聚居点面临灭顶之灾

**Conflict:** 聚居点防卫力量仅能抵挡三千只虫族，面对三万规模的军团完全没有胜算

**Pacing:** 先抑后扬，悬念迭起

#### 逐星的宣言

**Summary:** 林越主动提出驾驶机甲带领聚居点防卫队迎战虫族军团，在全体聚居点居民面前正式宣告自己的目标：统一所有人类势力，击败虫族与失控AI，重建人类文明，最终远征宇宙找到虫族入侵的真相。

**Characters:** 林越, 星火聚居点全体居民

**Location:** 星火聚居点防卫广场

**Events:**
- **林越** → announce → 逐星计划目标 (status) @ 星火聚居点防卫广场 | 林越获得了星火聚居点全体居民的支持，正式踏上逐星征程

**Beats:**
1. 聚居点高层会议上所有人都准备弃点逃亡
2. 林越主动站出来提出迎战方案
3. 向所有人展示自己的基因进化能力和机甲战力
4. 在防卫广场向全体居民发表宣言，提出逐星计划
5. 全员同意留下来迎战，林越登上机甲准备作战，监控显示虫族先锋部队已经抵达聚居点外围

**Opening Beat:** 会议上周叔红着眼宣布放弃聚居点，所有人准备一小时后撤离

**Closing Beat:** 林越操纵星尘-1机甲站在聚居点入口，远处地平线上已经出现了密密麻麻的虫族身影，防卫队全员举起武器等候作战指令

**State Change:** 林越正式确立长期奋斗目标，获得了第一批追随者，即将迎来第一场大规模战役

**Conflict:** 虫族军团规模远超聚居点防卫能力，这一战是林越逐星之路的第一次生死考验

**Pacing:** 高燃，史诗感强，留下强悬念
