# 穿越者的天道弈局

## Story Setup

### Genre(s)
- 仙侠
- 穿越
- 悬疑
- 黑暗奇幻


### Core Premise
网络作者林砚穿越为黑矿场矿奴，觉醒与生前写作风格绑定的诡异金手指。修仙界遍布穿越者，而‘缉厄司’以维护天道为名猎杀他们，实为抽取体内天道碎片修补破损天道。林砚必须在矿难复活循环中求生，躲避追杀，同时揭开世界阴谋并寻找同类。

### Theme
当创作风格化作异界生存的致命资本，穿越者如何在天道阴谋与同类相残的绝境中坚守人性底线，做出关乎存亡的抉择？

### Story Rules/Constraints
- 复活能力一旦暴露，必遭缉厄司锁定追杀或被其他穿越者胁迫利用。
- 金手指力量与作者生前创作题材的专注度和风格鲜明度正相关，断更或转型将导致能力衰退。
- 存在被封印的禁术级金手指‘死后夺取’，曾引发血案，是天道碎片极端具象化的危险案例。
- 缉厄司猎杀穿越者的根本目的是剥离其神魂与天道碎片，用以修补早已千疮百孔的天道。
- 过度使用金手指会引动天道反噬，轻则修为停滞，重则被天道标记成为众矢之的。
- 矿场复活能力受限于‘附矿场’区域，且每次复活都会损耗自身修为，尸体消失不留痕迹。
- 穿越者互助组织‘书友会’内部潜伏着缉厄司内鬼，擅长利用信息差制造猜忌与自相残杀。


### Target Audience
适合20-45岁喜爱高智商博弈、反套路设定与黑暗群像的深度网文读者，追求逻辑严密与人性刻画。

### Tone/Style
紧张阴郁、智斗反转频出、黑暗残酷中透人性微光，充满生存压迫与阴谋悬疑。

- **Type**: subplot
- **Importance**: 9/10

## Premises

### 金手指体系：附矿场复活 (生存类)
林砚专属金手指，死亡后在矿场周边区域复活。能力强度与对‘矿场’的理解深度相关，是生存与探索的核心。

**Progression System:**

**Level 1: 粗修复随机重生**
- Description: 死亡后在矿场‘附域’随机地点复活，身体仅恢复至死亡前一刻的粗修复状态（伤口闭合但极度虚弱、灵力紊乱），每次复活损耗部分修为，尸体消失。
- Requirements: 死亡触发，且复活点位于离死亡地点最近的矿场范围内。

**Level 2: 微控锚点重生**
- Description: 可微调复活地点至死亡点周边百丈内任意已知坐标，虚弱程度减轻，修为损耗降低30%，并能保留死亡前最后10息感官记忆。
- Requirements: 需在死亡前 consciously 标记一个锚点（如特定矿脉或岩石），且标记点未被破坏。

**Level 3: 记忆碎片预判**
- Description: 复活时自动提取死亡瞬间的‘记忆碎片’，可短暂预判3息内的致命危险（如落石、偷袭），虚弱期缩短至5息，修为损耗几乎可忽略。
- Requirements: 连续在同一矿场区域死亡超过10次，或目睹过三次以上大型矿难。

**Level 4: 矿区全域重生**
- Description: 复活范围扩大至整个黑矿场及周边五里山林，可主动选择是否携带一件死亡时手持的小型物品（如灵石、符纸），虚弱期仅1息。
- Requirements: 成功逃离矿场一次后再次死亡并复活，或在矿场内存活超过一年。

**Level 5: 代价规避**
- Description: 可主动选择‘不复活’以规避天道标记与修为损耗，但需支付等量寿元作为代价；或可将一次复活机会转移给接触过的其他穿越者（需对方同意）。
- Requirements: 修为达到筑基期，且对‘矿场’的规则理解达到极致（如知晓矿场地脉走向、历史矿难全部真相）。


### 金手指体系：轨迹推演 (信息类)
悬疑推理小说作者专属，通过灵气推演获取目标关键信息，是情报收集与反间谍的核心能力。

**Progression System:**

**Level 1: 基础轨迹**
- Description: 主动消耗少量灵气，推演单个目标1炷香内的行动轨迹，或破解一个简单隐藏秘密（如是否携带武器、是否撒谎），结果存在10%误差，目标修为越高误差越大。
- Requirements: 需清晰看到目标面部或感知其核心气息，且目标修为不超过自身。

**Level 2: 误差修正**
- Description: 误差降至5%，可推演更复杂的秘密（如是否属于某个组织、近期是否接触过特定人物），推演时间延长至3炷香。
- Requirements: 连续成功推演10次，且目标修为不超过自身两个小境界。

**Level 3: 多维推演**
- Description: 可同时推演3个目标的轨迹，或构建一个简单事件过去24小时的因果链，误差基本消失，但灵气消耗倍增。
- Requirements: 掌握至少5个不同目标的关键信息碎片，并在一次推演中全部验证正确。

**Level 4: 关键节点回溯**
- Description: 可推演目标过去7天内任意一个关键决策节点（如‘是否加入书友会’、‘是否向缉厄司告密’），并查看其当时内心的主要想法，但每次使用后自身会陷入半日‘推理眩晕’。
- Requirements: 在生死危机中凭借推演能力反败为胜至少三次，且目标曾与自身有深度交集。

**Level 5: 短时预演**
- Description: 可对单一目标未来10息内的行动进行‘预演’，生成最多3种可能分支，但每次使用后自身会陷入10息‘推理后遗症’（反应、思维速度下降50%），且若预演结果被目标察觉，将引动天道轻微反噬。
- Requirements: 修为达到金丹期，且曾成功预测一次涉及多方势力、影响重大的阴谋事件。
