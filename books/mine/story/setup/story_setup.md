# 无指令之境

## Story Setup

### Genre(s)
- 赛博哲学
- 悬疑科幻
- 心理惊悚


### Core Premise
主角发现自己身处一个旨在测试'人性本能'的绝对空域，所有技能与命令均被强制剥离。在这里，唯一的运行法则仅由'观测者的意志'决定，他必须通过纯粹的意志对抗世界的虚无。时间循环不断重启，每一次失败都让存在逼近极限。

### Theme
人类必须在剥离外部规则后，通过自我意志重新定义存在的权利。

### Story Rules/Constraints
- 意志即法则
- 无指令状态
- 存在即消耗
- 无外部干预
- 记忆无法被主动篡改
- 情绪无法被主观调用
- 反抗即消耗


### Target Audience
18-35 岁，偏好深度思考与反乌托邦题材的读者

### Tone/Style
叙事风格呈现冷峻、神秘、克制、压抑的特质，营造出令人心悸的寂静。

### Narrative Tense
present

### POV Style


## Storylines

### 意志重构
- **Type**: main
- **Importance**: 10/10
- **Description**: 主角在失去所有技能后，通过纯粹的意志力重建自身规则，对抗世界的虚无。每一次微小的坚持都可能引发剧烈的精神波动，导致记忆碎片化。

### 测试场博弈
- **Type**: main
- **Importance**: 8/10
- **Description**: 主角与测试场的逻辑核心进行对抗，每一次对抗都是对意志边界的试探。双方通过无声的数据流交换信息，试图在逻辑死循环中找到突破口。

### 记忆溯源
- **Type**: subplot
- **Importance**: 7/10
- **Description**: 主角寻找被剥离前'指令'的源头，揭示世界被测试的真正目的。沿途的幽灵数据暗示着某种古老的实验，试图唤醒被囚禁的意识。

### 本能觉醒
- **Type**: character_arc
- **Importance**: 9/10
- **Description**: 主角在极端环境中发现人类未被定义的原始本能，成为新的规则。这些本能如同潜伏的野兽，在混乱中进化出独特的生存策略。


## Premises

### 意志层级体系 (意志)
世界没有技能，只有意志强弱的层级划分，越高的意志能定义局部规则。在这种状态下，思维必须被压缩至最简形态，否则会被环境同化。

**Progression System:**

**Level 1: 意志萌芽**
- Description: 主角仅拥有基础感知，意志不足以定义规则，处于完全被动状态。
- Requirements: 通过极端意志活动积累初始精神力

**Level 2: 意志固化**
- Description: 主角能够短暂定义局部规则，但维持成本极高，思维开始受到环境侵蚀。
- Requirements: 在消耗中保持意志不灭，并成功通过一次环境同化测试

**Level 3: 意志定义**
- Description: 主角的意志强度足以覆盖局部法则，能够主动修改环境逻辑，对抗观测者。
- Requirements: 在连续三次意志消耗中，成功维持自身存在不被抹除


### 时间循环机制 (时间管理)
世界基于时间循环构建，每一次重置都清除非核心数据。主角必须在循环结束时做出选择，否则将陷入永恒的虚无与重复。

**Progression System:**

**Level 1: 初始循环**
- Description: 时间系统处于稳定运行状态，主角仅能感知到日常的时间流逝规律。
- Requirements: 完成基础生存测试，未触发直接惩罚

**Level 2: 循环波动**
- Description: 时间流速开始出现异常，记忆与身份出现模糊迹象，暗示即将发生重置。
- Requirements: 主角进行首次针对观测者的主动对抗

**Level 3: 强制循环**
- Description: 观测者判定主角威胁等级过高，启动清除协议，开始直接抹除存在或重置时间。
- Requirements: 主角在多次试探后，发现观测者内部的逻辑漏洞或弱点


### 观察者监视机制 (意识监控)
世界的核心逻辑通过无感知的观测者维持，任何反抗都会导致存在性消耗。这种消耗不仅是能量的流失，更是记忆与情感的抹除过程。

**Progression System:**

**Level 1: 无感观测**
- Description: 观测者处于潜伏状态，仅收集基础数据，未开启主动干预程序。
- Requirements: 主角完成基础生存测试，未触发直接惩罚

**Level 2: 感知消耗**
- Description: 观测者开始监测主角的意志波动，数据流中出现针对意识的异常波动。
- Requirements: 主角进行首次针对观测者的主动对抗

**Level 3: 强制干预**
- Description: 观测者判定主角威胁等级过高，启动清除协议，开始直接抹除存在。
- Requirements: 主角在多次试探后，发现观测者内部的逻辑漏洞或弱点
