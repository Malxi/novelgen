# Prompt 测试项目

## Story Setup

### Genre(s)
- 科技
- 技术
- 测试
- 元小说


### Core Premise
本设定旨在测试 AI 模型是否支持文件保存功能，作为测试项目，其核心内容为模拟文件保存过程，同时展示系统对 JSON 输出格式的执行情况。

### Theme
测试与限制的探索

### Story Rules/Constraints
- 必须严格遵守 JSON 格式输出，不得包含多余文本。
- 所有内容必须使用中文，不得出现英文字符（键名除外）。
- 禁止声称具备实际文件保存能力，需明确模拟性质。


### Target Audience
开发者、测试人员、技术爱好者

### Tone/Style
客观，技术，严谨

### POV Style


## Storylines

- **Type**: main
- **Importance**: 10/10
- **Description**: 系统接收用户指令，验证 JSON 格式生成能力，记录输出内容是否正确。

### 限制确认
- **Type**: character_arc
- **Importance**: 8/10
- **Description**: 模拟系统无法保存文件的场景，验证信息反馈机制。

### 格式验证
- **Type**: subplot
- **Importance**: 7/10
- **Description**: 检查输出是否包含所有必填字段，验证结构完整性。


## Premises

### 测试环境 (technical)
模拟一个 AI 系统接收用户指令并尝试生成特定格式输出。

**Progression System:**

**Level 1: 初始指令**
- Description: 用户输入测试指令，系统识别意图为 JSON 生成。
- Requirements: 用户输入必须为有效中文指令

**Level 2: 格式构建**
- Description: 系统开始构建 JSON 结构，填充预设字段。
- Requirements: 系统必须理解指令并识别格式要求

**Level 3: 输出验证**
- Description: 系统输出最终 JSON 内容，验证是否符合要求。
- Requirements: 输出必须为有效 JSON，且内容无乱码

**Level 4: 限制说明**
- Description: 系统明确告知无法进行实际文件保存，仅模拟过程。
- Requirements: 必须明确说明技术限制
