# 灵石与分赃

林砚的脚步刚从石室门缝里抽出来，背后那股阴冷的风就像一只不肯松口的手，贴着他后颈往衣领里钻。他把麻袋往肩上一提，麻袋里硬块互相碰撞，发出闷闷的“咯”声——那声音在井下岔道里被石壁一层层放大，听得他心脏也跟着一跳。

岔道里没有灯，只有矿脉里渗出的微弱磷光似的冷亮，照得岩壁上湿滑的水痕像蛇一样蜿蜒。他刚拐过一块凸起的黑石，脚下碎渣一响，前方就有一道影子从侧壁阴影里滑出来，像早就等在这里。

“拿的什么？”声音低哑，带着砂砾磨喉的粗。

林砚的手瞬间按住麻袋口，指节用力到发白。他抬眼，看见阿蛮半个身子挡在岔道中间。那少年个头不算高，肩背却硬得像一块压过水的岩，脸上沾着矿灰，眼睛在暗里反着一点亮，盯着麻袋的目光不闪不避，像盯着一块能决定今夜能不能活下去的肉。

阿蛮身后更远一点，黑六缩在另一条岔口的阴影里，像一条不敢出声的狗。他没靠近，却也没走，明显是在等结果。

林砚喉头发紧，舌尖尝到一股铁锈味。他知道自己不该在这种地方发出任何“多余”的声音，可麻袋里的灵石偏偏就像故意提醒他：你带着命。

阿蛮伸出一只手，手指关节粗大，指缝里全是黑泥，“给我看看。”

林砚没有动，只把麻袋往身后藏了一寸。他听见自己呼吸落在耳膜上，像敲鼓。井下的风从岔道里穿过，带着潮腥与腐败的矿气，把人的胆气一点点刮薄。

“你跟着我？”林砚压低声音，尽量让语气听起来平稳，“这地方谁都能走。”

阿蛮的嘴角扯了一下，不算笑，更像在忍耐什么，“我不跟着你，我跟着吃的。”他往前一步，靴底碾碎碎石，“你从石室出来，肩上重了。别当我瞎。”

黑六在远处咽了口唾沫，发出很轻的一声响，立刻又把头缩回阴影里。

林砚心里一沉。阿蛮说得没错——他出来得太急，连伪装都来不及做。可现在把麻袋给对方看，等于把脖子伸出去给刀试试锋利。

“你想要什么？”林砚问。

阿蛮盯着他，眼神像钉子，“分。”

“分什么？”

“分你拿到的。”阿蛮的声音更低，像贴着石壁说话，“不分，我就去上头报。你知道报什么——私藏灵石，偷矿脉，挖到好东西不交。你这种新来的……死得最快。”

林砚的指尖冰凉。他见过矿场的“规矩”：挖到灵石不上交，轻则断指，重则直接拖去“回炉”，那种回炉不是干活，是把人丢进塌方区当诱饵。最可怕的是——死了也未必是解脱。矿场的附域像一张网，他已经尝过一次“死也回不去”的滋味，那种醒来又回到井下的恐惧，比疼更深。

他盯着阿蛮的手。那手伸出来，掌心朝上，像讨债。

“你凭什么觉得我会信你不告密？”林砚问。

阿蛮没有立刻回答。他把伸出的手收回去，指尖在自己大腿侧蹭了一下，把掌心的汗和泥一起抹掉。那动作很轻，却透出一种倔：他不是求人，他是在立规矩。

“矿奴也有规矩。”阿蛮说，“见者有份。拿独了，必有人把你卖了换活路。你不分，我不一定能活；我分到一口，我就有理由替你瞒一回。”

林砚听着，心里反而更紧。阿蛮的逻辑冷硬到近乎残酷，但偏偏在矿场这种地方，冷硬才像真的。他不说“我讲义气”，只说“我有理由”。

他缓缓松开按住麻袋口的手，却没立刻解开。他让麻袋垂在身侧，像随时能甩出去砸人。

“你跟我到这岔道，是早就盯上石室了？”林砚问。

阿蛮的视线从麻袋挪到林砚脸上，像在衡量他到底懂不懂这里的活法，“石室的味道不对。风从里面出来，带灵气。”他顿了顿，又补上一句，“你这种人不该能进去。”

这句话像一根冷针，扎进林砚皮下。他强迫自己不露出任何反应，只淡淡道：“运气。”

阿蛮不接这话。他抬起下巴，朝黑六的方向点了一下，“他也看见了。你要是想独吞，先想好怎么让他闭嘴。”

黑六被点名，身体一抖，急忙从阴影里探出半张脸，讪笑着摆手，声音发颤：“我、我没看见啥……真没看见。阿蛮哥说笑了。”

他越否认，越像默认。

林砚胸口一阵发闷。他忽然意识到，自己带着灵石从石室出来，等于在矿场最饥饿的地方端着一碗肉汤走夜路。阿蛮只是第一个拦路的，绝不会是最后一个。

他吸了一口气，空气里有潮湿的霉味，呛得喉咙发痒。他把麻袋拉到胸前，解开绳结一小截，让里面的光漏出来一点——不是火光，是一种浸润的青白。那光一出来，岔道壁上的水痕都像亮了三分。

阿蛮的喉结滚了一下，眼神却没有贪婪到失控，只是更冷、更专注。

林砚伸手进去，指尖碰到那些硬块。灵石的表面冰凉，却在他触碰的瞬间，像有细小的电流沿着皮肤往上爬，钻入经络深处。他的呼吸不由自主地停了一拍——那种感觉比上一次灵风刺激更直接，更清晰，仿佛石头里有一条条细线，牵着井下深处某个更庞大的脉动。

他不敢沉迷，立刻抽回手，握住其中两块，拿出来放在掌心。青白的石头不大，棱角打磨得粗糙，像从矿里硬掰下来的骨。

“下品灵石。”林砚的声音尽量平静，可他知道自己眼底一定有光，“我拿到的不多。”

阿蛮盯着那两块灵石，伸手，却没有马上抢。他先看林砚的脸，像确认他是不是在设套。

“怎么分？”阿蛮问。

林砚把两块灵石往前递一寸，又停住。他的手悬在半空，像把命悬在刀口上，“你想要多少？”

阿蛮沉默了一会儿，忽然伸出两根手指，“三成。”

黑六在后面倒吸一口凉气，立刻又捂住嘴。

林砚心里冷笑：开口就三成，是把他当肥羊。可他也明白，阿蛮不是不懂分寸的人，他敢开这个价，说明他认为林砚拿到的远不止两块。

“你怎么不说一半？”林砚问。

阿蛮的眉峰动了一下，像被侮辱，“我不是抢。我是要你活。”他抬眼望向岔道更深处，那里传来极远的铁器敲击声，像某种永不停止的心跳，“你一个人吞了，活不过今晚。你分了，我替你挡一挡。挡不住，你也别怪我。”

林砚看着阿蛮的眼睛，忽然想起这少年平时寡言，却在矿奴之间很少被欺负——不是因为他能打，而是因为他讲规矩，别人也愿意按规矩来。这是矿场里一种怪异的秩序：人人都像野狗，但野狗也有自己的圈。

他垂下眼，装作思考，实际上飞快权衡：给阿蛮三成，等于买一张“闭嘴”的票，也买一个能在矿场里行走的向导。更重要的是，阿蛮提到“挡一挡”，说明他知道如何遮掩，如何把事压下去。

他不可能永远靠复活去赌。每死一次，代价都像在暗处累积——他能感觉到某种东西在盯着自己，像矿脉深处的阴影有了呼吸。要离开矿场，他需要活人之间的规则，而不是死后的侥幸。

“好。”林砚说，“三成。但你也得按规矩来。”

阿蛮的眼神一凝，“你说。”

林砚把麻袋口又打开一些，让阿蛮看到里面还有一堆青白的石头。他看到阿蛮的瞳孔在那光里缩了一下，但他没有失态，只是呼吸更重。

林砚道：“第一，今天你看见的，谁都不能说。第二，黑六也在这，你要他闭嘴，你得一起担。第三，我分你三成，但你得告诉我——你怎么知道石室？你还知道什么岔道能避开巡矿的？”

黑六听到自己名字，急忙从阴影里挪出半步，声音快得像倒豆子：“我闭嘴！我肯定闭嘴！我啥也没看见！我……我还能帮忙望风！”

阿蛮回头看了黑六一眼，那一眼不重，却像一块石头压在黑六喉咙上。黑六立刻缩了缩脖子，连连点头。

阿蛮再看回林砚，“你要路？”

“我要活路。”林砚纠正。

阿蛮的嘴唇抿紧。他像是在心里把什么东西掰开再合上，最后才道：“石室不是我发现的，是老矿奴传的。说下面有‘吃人的门’，进去的人要么发了，要么没了。你能出来，说明你命硬。”

林砚的背脊发凉。他记得石室里的东西：那不像单纯的矿洞，更像某种被封住的“口”。他问：“老矿奴是谁？”

阿蛮摇头，“死了。早死了。矿场不缺死人。”他说这话时，声音没有颤，只是更平，“至于巡矿……他们走大路。小路要记味道，记风，记水声。你愿意分，我带你走一段。”

林砚盯着他，试图从他脸上找出一丝虚假，可阿蛮的表情像石头，能看见的只有坚硬。

“你先拿。”林砚把手里的两块灵石递过去，“算定金。剩下的，出去再分。”

阿蛮接过灵石，动作很稳。他没有立刻塞进怀里，而是用拇指在灵石棱角上摩挲一下，像确认这不是普通石头。那一瞬间，他眼底闪过极淡的热，却很快压下去，像怕自己露出不该露的东西。

“出去？”阿蛮抬眼，“你想出井？”

林砚没回答，只把麻袋口重新扎紧。他不能在这里把计划说出来，尤其黑六还在。他只是问：“你敢不敢？”

阿蛮盯着他，像第一次真正打量这个“新来的”。半晌，他吐出两个字：“敢。”

黑六在旁边急得直搓手，终于忍不住插话：“那、那我呢？阿蛮哥，林砚哥……我也、我也能去吗？我不想一辈子在这儿挖死！”

阿蛮没有立刻回应黑六，只把灵石塞进腰间破布里，勒紧。那动作像把某种希望绑在骨头上。他转身，走到黑六面前，抬手就把黑六的衣领一拽，把人拽得踉跄半步。

“你闭嘴，跟着走。”阿蛮的声音像铁，“再多一句，我先把你舌头拽下来。”

黑六脸色煞白，连连点头，眼睛却黏在林砚的麻袋上，像黏在一堆能救命的肉上。

林砚把这一切看在眼里，心里却没有放松。他知道黑六这种人最难控制：胆小，贪，嘴碎。可阿蛮把黑六带上，也可能是另一层保护——三个人知道，彼此牵制，反而不容易有人单独去告密。

阿蛮领着路，脚步轻得不像矿奴。他不走主岔道，而是沿着右侧一条几乎被碎石掩住的缝隙钻进去。缝隙里潮气更重，岩壁贴着肩膀磨过去，粗粝的石粉蹭在皮肤上，刺得发痒。林砚背着麻袋，必须侧身才能过，麻袋不时擦到墙，发出轻微的“沙沙”声。

他每发出一点声音，心就跟着紧一下。井下的黑暗像有重量，压得人喘不过气。

走了一段，前方忽然传来极轻的说话声，还有铁链拖地的响动。阿蛮立刻停下，抬手示意。三个人贴到岩壁阴影里，连呼吸都压到最浅。

一队巡矿的从另一条岔道拐过来，灯火摇晃，照出他们腰间挂着的鞭子与短刀。为首的监工骂骂咧咧，声音在石壁间反弹：“昨晚塌了两个人，今儿还不够数！都给我挖，挖不出灵石就把命填进去！”

灯光扫过岔道口，林砚的心几乎要跳出喉咙。他把麻袋抱得更紧，灵石的冷意透过粗布渗进胸口，像在提醒他：被发现就完。

阿蛮的背贴着岩壁，肩膀纹丝不动。他甚至连眼睫都不眨，只在灯光快扫到他们时，用脚尖极轻地把一块碎石拨到前方，碎石滚出去，“咔”的一声。

监工的灯立刻转过去，骂了一句，抬脚踹了踹那边的石堆，见没有动静，才不耐烦地挥手带队继续走。铁链声渐远，黑暗重新合拢。

黑六憋到脸发紫，等巡矿的脚步声彻底消失，才猛地吸气，差点发出咳。阿蛮一巴掌按住他的嘴，把他整个人按回石壁上，直到黑六眼里冒泪，才慢慢松开。

“想死别带上我们。”阿蛮低声道。

黑六拼命摇头，眼泪和鼻涕糊一脸，硬是没敢出声。

林砚看着阿蛮那一套干净利落的动作，心里那点戒备反而更复杂：这少年确实能在矿场里活下来，而且活得像个“人”，哪怕这“人”的底线只剩一点点。

继续往前，缝隙尽头是一处低洼，水从岩缝里滴下来，积成一小滩黑水。阿蛮蹲下，用手指蘸了蘸水，放到鼻下闻了一下。

“这水里有药味。”阿蛮说。

林砚一愣，“药味？”

阿蛮点头，“上头洗矿石会放东西。顺着这水走，能绕到弃井边。弃井上去……能到废料场。”

林砚的脑子飞快转动。废料场他听过，矿奴被赶去捡碎矿渣的地方，巡得松，但也更乱。那是最接近“外面”的边缘之一——如果能从废料场找到缺口，也许真能离开矿场附域的范围。

他抬眼看阿蛮，“你早就想走？”

阿蛮的脸在黑里看不清，只能看见他下颌的轮廓绷得很紧。“想。”他吐出一个字，“但一个人走不出去。”

林砚没有再追问。他知道再问下去就像把刀往对方心口顶：你凭什么信我？你又凭什么让我信你？

他们沿着滴水的方向走，越走越冷。林砚能感觉到麻袋里的灵石像一团微弱的火——不是热，而是一种牵引，仿佛他靠得越近，周围的灵气流动就越明显。他甚至能在某些岔口处隐约“看见”风的走向：哪里干燥，哪里潮湿，哪里有人的气味，哪里有某种更难以言说的阴沉。

那感觉让他心底发毛。他不确定这是机缘，还是石室带出来的后遗症。

走到一处更宽的岔道时，阿蛮忽然停下，回头看他，“现在分。”

林砚心里一紧，“这里？”

“这里安静。”阿蛮道，“再往前就是废料场的风口，容易撞人。你不现在分，我不放心。”

黑六一听“分”，眼睛立刻亮了，又立刻被阿蛮一眼瞪回去。

林砚知道躲不过。他把麻袋放到地上，解开绳结。青白的光再次溢出来，照得三张脸都苍白了一瞬。黑六的喉咙发出“咕”的一声，像饿极的人看见馒头。

林砚把灵石一块块倒出来，落在湿石上，发出清脆的碰撞声。他数得很快——他不敢久留，怕声响引来人。总共十六块，下品灵石，大小不一，有两块裂了角，但仍有光。

阿蛮的眼神始终稳，直到数清，才道：“三成，五块。”

林砚没有讨价还价。他把五块推过去，其中包括一块稍大的。他不想在这种时候抠细账——抠得越细，越像要翻脸。

阿蛮伸手把五块收拢，用破布包好，动作利索。收完，他没有立刻起身，而是抬眼看林砚，“你给多了。”

林砚一怔。

阿蛮把那块稍大的灵石推回来，“我说五块，不说大的小的。你要我挡事，就别用这种东西压我。我不欠你的。”

黑六在旁边看得眼睛都直了，像看见有人把肉往回推，嘴唇哆嗦着，几乎要喊出来“我欠我欠”，又硬生生咽回去。

林砚盯着阿蛮推回来的灵石，心里某处忽然松了一下。他把那块灵石收回，点点头，“行。按规矩。”

阿蛮这才起身，拍了拍膝盖上的泥，“记住，你欠我一条路，我欠你一回瞒。两清。”

“还没出去呢。”林砚说。

阿蛮看他一眼，那眼神像在说：出去不出去，都是后话；规矩先立。

他们重新上路。越往前，风越大，带着一股铁锈和腐烂混在一起的味道，像某处堆着大量废渣和血肉。林砚的心跳得更快，麻袋里剩下的十一块灵石贴着他背脊，像一排冰冷的牙。

就在前方风声最急的地方，忽然传来一声很轻的“叮”。

像金属碰到石头。

阿蛮的脚步猛地一顿，手掌下意识摸向腰间——那里藏着他的灵石，也藏着一把磨得发亮的短凿。黑六更是吓得一缩，差点撞到林砚。

林砚也停住，耳朵竖起来。风声里，那“叮”声又响了一下，接着是一个人的低哼，像压着痛。

有人在前面。

而且不止一个人。

阿蛮回头，用极低的气声吐出一句：“不是巡矿的脚步。”

林砚喉头发紧。他把麻袋往肩上又提了提，指尖悄悄扣住袋口的绳结——一旦需要，他可以立刻把灵石撒出去制造混乱，也可以抱着袋子冲。

阿蛮贴着岩壁往前挪一步，侧耳听，眉头越皱越紧。下一瞬，他猛地转头看向林砚，眼里第一次露出明显的警告。

“前面的人，”阿蛮几乎不出声，“像是在等我们。”
